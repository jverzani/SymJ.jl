    Piecewise functions#

    SymJ.dirac — Tuple{Any}

    source 
    SymJ.dirac(x, k = 0)

    The Dirac delta (with k, its k-th derivative): 0 away from 0, the derivative of SymJ.heaviside, with ∫ f(x) dirac(x - a) dx = f(a) heaviside(x - a). Not exported.

    SymJ.heaviside — Tuple{Any}

    source 
    SymJ.heaviside(x, h0 = 1/2)

    The unit step: 0 for x < 0, 1 for x > 0, and h0 at 0. Its derivative is SymJ.dirac. Not exported.

    SymJ.piecewise — Tuple{Vararg{Pair}}

    source 
    SymJ.piecewise(c₁ => v₁, c₂ => v₂, …)
SymJ.piecewise(ex)
SymJ.piecewise(cs::Cases)

    A piecewise function: v₁ where c₁ holds, else v₂ where c₂ holds, and so on. A condition is a relation (x ≪ 0), a tuple of them that all hold ((0 ≦ x, x ≪ 1)), or true. Not exported.

    With one expression, writes its heaviside, sign, abs, max and min as piecewise functions (taking their arguments to be real); with cases, makes them one expression.

    f = SymJ.piecewise(x ≪ 0 => -x, true => x^2)
f(x => -2), diff(f, x)          # 2, piecewise(x ≪ 0 => -1, true => 2x)

    SymJ.piecewise_fold — Tuple{Any, Sym}

    source 
    SymJ.piecewise_fold(e, x; assume = nothing)
SymJ.piecewise_fold(e; assume = nothing)

    e, with piecewise functions (and heaviside, sign, abs, max, min) in x inside sums, products and other functions, as one piecewise function of x: its value between consecutive breakpoints (where a condition changes) and at each breakpoint, neighbours with the same value merged. Without x, the one symbol in the conditions. The breakpoints are ordered as numbers, or, with parameters (taken to be real), by the assumptions (assume, or an assuming block); when they do not decide an order the result is a SymJ.Cases, a folded function for each (a < b, a = b, a > b). Not exported.

    @syms x a
SymJ.piecewise_fold(abs(x) + abs(x - 1), x)
# piecewise(x ≦ 0 => -2x + 1, x ≦ 1 => 1, true => 2x - 1)
SymJ.piecewise_fold(SymJ.piecewise(a ≫ 1 => a - 1//2, true => a^2 - a + 1//2) -
                    SymJ.piecewise(a ≫ 0 => 0, true => a^2))
# piecewise(a ≦ 0 => -a + 1/2, a ≦ 1 => a^2 - a + 1/2, true => a - 1/2)
