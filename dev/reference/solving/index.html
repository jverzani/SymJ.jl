    Solving equations#

    See also rsolve, dsolve.

    CommonSolve.solve — Tuple{AbstractVector{<:Relation}, Union{Tuple, AbstractVector}}

    source 
    solve(eqs::AbstractVector{<:Relation}, vars)

    Solve a system of equations (written with ~) for the variables vars. The result is a vector of solutions, each a Dict with every one of vars as a key; an inconsistent system gives an empty vector. Both arguments must be vectors (or tuples): one equation in one unknown is solve(eq, x), which gives a vector of values instead.

    • Linear systems are solved by Gauss–Jordan elimination. An underdetermined system has one solution, with the pivot variables given in terms of the free ones, which map to themselves.

    • Polynomial (and rational) systems are solved through a lex Gröbner basis (groebner), which is triangular, by back-substitution. The values are exact where the equations in one variable along the way can be solved exactly, numeric otherwise. With infinitely many solutions, the variables left free map to themselves.

    Coefficients may involve parameters. Where the solution divides by an expression in them (a pivot of the elimination, a coefficient of the Gröbner basis, a denominator of a solution) that could vanish, the result is a Cases value, the case where it vanishes solved again with it substituted; a case that cannot be solved so holds an error. assume for a system states facts about parameters and unknowns: x ∈ ℝ makes abs(x), real(x) real-valued (and keeps only real solutions), x ≫ 0 keeps the solutions with x > 0; without it the unknowns are complex.

    solve([a*x + y ~ 1, x - y ~ 2], [x, y])
# a == 0 => [Dict(x => 3, y => 1)], a == -1 => [], a != 0, a != -1 => [Dict(x => 3/(a + 1), y => (1 - 2a)/(a + 1))]
    solve([x + y ~ 3, x - y ~ 1], [x, y])          # [Dict(x => 2, y => 1)]
solve([x + y + z ~ 1, x - z ~ 0], [x, y, z])    # [Dict(x => z, y => 1 - 2z, z => z)]
solve([x^2 + y^2 ~ 1, x ~ y], [x, y])          # [Dict(x => -√2/2, y => -√2/2), Dict(x => √2/2, y => √2/2)]
solve([x*y ~ 1, x + y ~ 3], [x, y])

    CommonSolve.solve — Tuple{Relation, Sym}

    source 
    solve(eq::Relation, x; assume = nothing, drop_empty = false)

    The solutions of the equation eq (written with ~, e.g. x^2 ~ 4) for x, as a vector of distinct expressions. The equation must be polynomial or rational in x; its coefficients may involve other symbols. Solutions are exact through degree 4 and for equations that factor into such pieces; irreducible factors of higher degree with numeric coefficients give numeric (floating point) roots. Numeric solutions are sorted, real ones first. An equation with no solution gives an empty vector. A solution must be in the equation's domain: (x^2 - 1)/(x - 1) ~ 2 has none, though cancelling gives x + 1 = 2. For a system, solve([eqs...], [vars...]), giving a vector of Dicts; mixing the forms (solve(eq, [x]), solve([eq], x)) is an error. An unknown may also be a function call or a derivative (u(x), diff(u(x), x)), as in implicit differentiation; other derivatives of it are held as they are. In a system, abs, real, imag and conj of the unknowns are solved over the complex numbers, through each unknown's real and imaginary parts ([I*R ~ 220, abs(I) ~ 2]: a family written with a free part such as R_im); with the unknowns assumed real (assume = (I ∈ ℝ,)), abs is ± its argument and only real solutions are kept (I = ±2).

    An equation through sin or cos gives the solutions for its argument in [0, 2π], each once: cos(x) ~ 0 gives [π/2, 3π/2], sin(x) ~ -1//2 gives [7π/6, 11π/6], and cos(x) ~ 1 gives [0, 2π] (with the interval closed, 0 brings 2π). tan(u) = r gives atan(r). When the assumptions keep x in a bounded interval and the argument is linear in x, every solution in that interval is given (cos(2x) ~ 1//2 with 0 ≤ x ≤ 2π: four). An equation c*floor(u) + d ~ 0 (or ceil) holds on intervals: its solution is a set, as for an inequality (floor(x) ~ 2 gives [2, 3)).

    solve(x^2 - 2 ~ 0, x)          # [-sqrt(2), sqrt(2)]
solve(x^2 ~ -1, x)             # [-im, im]
solve(diff(x^2 + u(x)^2 - 1, x) ~ 0, diff(u(x), x))   # [-x/u(x)]

    With parameters, the solutions are correct for every value of them: where a coefficient could vanish, the result is a Cases value, a list of conditions => solutions (called with values, cs(a => 4), it gives that case's solutions). The cases come from the leading coefficients of a polynomial (the next one when it vanishes), from denominators free of x (where they vanish the equation is not defined: no solutions), and from denominators of the solutions. A case in which every value of x is a solution holds an error. Assumptions that settle a coefficient give the plain answer.

    solve(a*x + b ~ 0, x)          # a == 0, b == 0 => (every x), a == 0, b != 0 => [], a != 0 => [-b/a]
solve(a*x + b ~ 0, x; assume = (a ≫ 0,))   # [-b/a]
solve(exp(a*x) ~ 2, x)         # a == 0 => [], a != 0 => [log(2)/a]
solve(x^2 ~ a, x)              # [-sqrt(a), sqrt(a)]

    With assumptions (assume = (x ≫ 0,), an Assumptions, or inside assuming), only the solutions they allow for x are kept: those in its number set (x ∈ ℝ), its range (x ≫ 0), and consistent with its relations to other symbols. Facts about the other symbols are used to decide that. For a real x, a floating point root whose imaginary part is tiny beside its size (a double root split by rounding, 264 ± 6e-6im) is taken as real, with a warning. When the answer depends on something the assumptions leave open, the result is again a Cases value.

    solve(x^2 ~ 4, x; assume = (x ≫ 0,))                # [2]
solve(x^2 ~ a, x; assume = (x ∈ ℝ, a ∈ ℝ))         # a < 0 => [], a == 0 => [0], a > 0 => [-√a, √a]
solve(x^2 ~ a, x; assume = (x ≫ 0,))                # a > 0 => [√a], !(a > 0) => []

    drop_empty = true drops the cases with no solutions (and those holding an error, such as every value of x solving the equation), and when one case is left gives its solutions alone: the conditions under which they hold are then not shown.

    solve(x^2 ~ a, x; assume = (x ≫ 0,), drop_empty = true)   # [√a] (for a > 0)

    SymJ.SymInterval

    source 
    SymInterval

    An interval of the real line with exact endpoints: lo, hi (nothing for -∞, ∞) and whether each end is closed. A point is the closed interval [a, a].

    SymJ.SymSet

    source 
    SymSet

    A finite union of disjoint intervals with exact endpoints, sorted and merged; the solutions of an inequality (solve). Supports in, ∪, ∩, setdiff, ⊆, isempty; the intervals are S.intervals. Calling tests membership: S(2), or S(x => 2) for a set from solve(ineq, x) (which records its variable).

    SymJ.CylindricalSet

    source 
    CylindricalSet

    The solution of a system of linear inequalities in several unknowns, as nested bounds (a cylindrical description): the last unknown ranges over an interval, and each earlier one lies between bounds in the later ones; unknowns fixed by equations are given last. Not exported.

    Calling substitutes into the constraints it was solved from: C(x => 1, y => 4) is a Bool once every unknown has a value; with some unknowns given, C(y => 1) is the solution set in the others (a SymSet for one, a CylindricalSet for several). pt in C for a point given as a Dict is the same test.
