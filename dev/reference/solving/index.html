    Solving equations#

    See also rsolve, dsolve.

    CommonSolve.solve — Tuple{Relation, Sym}

    source 
    solve(eq::Relation, x; assume = nothing, drop_empty = false)

    The solutions of the equation eq (written with ~, e.g. x^2 ~ 4) for x, as a vector of distinct expressions. The equation must be polynomial or rational in x; its coefficients may involve other symbols. Solutions are exact through degree 4 and for equations that factor into such pieces (and for higher degrees in special forms: a xⁿ + b, cyclotomic polynomials, compositions); an irreducible factor of higher degree that solve finds no roots in radicals for is an error, as solve gives only exact solutions: SymJ.fsolve gives its roots numerically. (Most such factors have no roots in radicals. A quintic over the rationals that has them, its Galois group solvable, as x^5 - 5x + 12, gets them, through its Lagrange resolvents; they are large expressions.) Solutions are sorted, real ones first. An equation with no solution gives an empty vector. A solution must be in the equation's domain: (x^2 - 1)/(x - 1) ~ 2 has none, though cancelling gives x + 1 = 2. For a system, solve([eqs...], [vars...]), giving a vector of Dicts; mixing the forms (solve(eq, [x]), solve([eq], x)) is an error. An unknown may also be a function call or a derivative (u(x), diff(u(x), x)), as in implicit differentiation; other derivatives of it are held as they are. In a system, abs, real, imag and conj of the unknowns are solved over the complex numbers, through each unknown's real and imaginary parts ([I*R ~ 220, abs(I) ~ 2]: a family written with a free part such as R_im); with the unknowns assumed real (assume = (I ∈ ℝ,)), abs is ± its argument and only real solutions are kept (I = ±2). Unknowns that appear only through exponentials (2^x + 2^y ~ 10), one function (log(x), sin(2y)), or sin and cos of one argument are solved for those first, the others polynomially ([x^2 + y^2 + 2x*y*sin(a) ~ 25, …]); an unknown an equation gives explicitly (y ~ log(x)) is substituted into the others.

    An equation through sin or cos gives the solutions for its argument in [0, 2π], each once: cos(x) ~ 0 gives [π/2, 3π/2], sin(x) ~ -1//2 gives [7π/6, 11π/6], and cos(x) ~ 1 gives [0, 2π] (with the interval closed, 0 brings 2π). tan(u) = r gives atan(r). When the assumptions keep x in a bounded interval and the argument is linear in x, every solution in that interval is given (cos(2x) ~ 1//2 with 0 ≤ x ≤ 2π: four). An equation c*floor(u) + d ~ 0 (or ceil) holds on intervals: its solution is a set, as for an inequality (floor(x) ~ 2 gives [2, 3)).

    solve(x^2 - 2 ~ 0, x)          # [-sqrt(2), sqrt(2)]
solve(x^2 ~ -1, x)             # [-im, im]
solve(diff(x^2 + u(x)^2 - 1, x) ~ 0, diff(u(x), x))   # [-x/u(x)]

    With parameters, the solutions are those for generic values of them: an expression in the parameters alone is taken to be nonzero unless the assumptions make it zero, so a*x ~ b gives b/a (the same rule as limit and integrate). Inverses are principal values: a symbolic exponent gives the principal root (x^a = b gives b^(1/a), not the other roots b^(1/a) e^(2πik/a), so x^n ~ 1 gives [1] even for a positive integer n), exp(x) ~ b gives log(b) (not log(b) + 2πik), and a trigonometric equation gives its roots in one period, [0, 2π] (sin(x) ~ 0 gives [0, π, 2π]). Facts that make a coefficient vanish give that case's answer. A root that holds for only some parameter values (a^2 for sqrt(x) ~ a) is kept as it is for complex parameters, and comes with its condition when they are assumed real.

    solve(a*x + b ~ 0, x)                          # [-b/a]
solve(a*x + b ~ 0, x; assume = (a ~ 0,))       # [] (b ≠ 0)
solve(exp(a*x) ~ 2, x)                         # [log(2)/a]
solve(x^2 ~ a, x)                              # [-sqrt(a), sqrt(a)]
solve(x^a ~ 2, x)                              # [2^(1/a)]
solve(sqrt(x) ~ a, x)                          # [a^2]
solve(sqrt(x) ~ a, x; assume = (a ∈ ℝ,))       # a < 0 => [], a ≥ 0 => [a^2]

    With assumptions (assume = (x ≫ 0,), an Assumptions, or inside assuming), only the solutions they allow for x are kept: those in its number set (x ∈ ℝ), its range (x ≫ 0), and consistent with its relations to other symbols. Facts about the other symbols are used to decide that. For a real x, a floating point root whose imaginary part is tiny beside its size (a double root split by rounding, 264 ± 6e-6im) is taken as real, with a warning. When the answer depends on something the assumptions leave open, the result is again a Cases value.

    solve(x^2 ~ 4, x; assume = (x ≫ 0,))                # [2]
solve(x^2 ~ a, x; assume = (x ∈ ℝ, a ∈ ℝ))         # a < 0 => [], a == 0 => [0], a > 0 => [-√a, √a]
solve(x^2 ~ a, x; assume = (x ≫ 0,))                # a > 0 => [√a], !(a > 0) => []

    An inequality (≪, ≦, ≫, ≧, ≶) gives its set of solutions, a union of intervals. With parameters, which an order takes to be real, an inequality rational in x gives its set by cases on them: on the realness of its roots and poles in x, their order, and the sign between them. The parameters are generic, as for equations, so a*x ≫ 1 has no case a = 0.

    solve(a*x ≫ 1, x)        # a < 0 => (-∞, 1/a), a > 0 => (1/a, ∞)
solve(x^2 ≦ a, x)        # a < 0 => ∅, a == 0 => {0}, a > 0 => [-√a, √a]

    A linear system in integer unknowns (x ∈ ℤ) has its integer solutions: a family of them is written in new integer parameters C1, C2, … (as the constants of dsolve), each solution given once.

    solve([-123x + 77y ~ 3], [x, y]; assume = (x ∈ ℤ, y ∈ ℤ))   # [Dict(x => 77C1 + 15, y => 123C1 + 24)]
solve([2x + 4y ~ -3], [x, y]; assume = (x ∈ ℤ, y ∈ ℤ))      # [] (no integer solutions)

    drop_empty = true drops the cases with no solutions (and those holding an error, such as every value of x solving the equation), and when one case is left gives its solutions alone: the conditions under which they hold are then not shown.

    solve(x^2 ~ a, x; assume = (x ≫ 0,), drop_empty = true)   # [√a] (for a > 0)

    SymJ.fsolve — Union{Tuple{AbstractVector{<:Relation}, AbstractVector}, Tuple{AbstractVector{<:Relation}, AbstractVector, Any}}

    source 
    SymJ.fsolve(eqs, vars, hints = nothing; domain = ℝ)

    Solutions of the system of equations eqs (a vector, each written with ~) in the unknowns vars, numerically, as a vector of Dicts as solve gives for a system. A polynomial system (polynomials or rational functions in the unknowns) gives all of its solutions: the real ones (in the ranges given), or with domain = ℂ the complex ones too, through solve's exact elimination. Another system gives one solution, as Maple's fsolve for a system. eqs must have no symbols but vars, and as many equations as unknowns. Not exported.

    For a system that is not polynomial, hints narrows the search, one pair for an unknown: x => (a, b) looks for x in [a, b], x => x0 starts from x0. An unknown without one is looked for in [-10, 10]. The search is Newton's method, damped, with the exact Jacobian, from the starting values given, or else from points spread over the ranges (the same each call); with domain = ℂ a complex starting value may lead to a complex solution. A system whose search finds no solution is an error, not an empty vector, since one may exist elsewhere.

    @syms x y
SymJ.fsolve([x^2 + y^2 ~ 4, exp(x) ~ y], [x, y])                       # one of its two solutions
SymJ.fsolve([x^2 + y^2 ~ 4, exp(x) ~ y], [x, y], [x => (0, 2)])        # x ≈ 0.4...
SymJ.fsolve([sin(x) ~ y, x + y ~ 1], [x, y], [x => 0.5, y => 0.5])
SymJ.fsolve([x^3 + y^3 ~ 1, x^2 + y ~ 3], [x, y])                      # all its real solutions

    SymJ.fsolve — Union{Tuple{Relation, Sym}, Tuple{Relation, Sym, Tuple{Any, Any}}}

    source 
    SymJ.fsolve(eq, x, (a, b) = (-Inf, Inf); domain = ℝ)

    The roots of the equation eq (written with ~) in x, numerically, as Maple's fsolve: by default the real roots in the interval [a, b] (the whole line when it is not given; either end may be infinite), sorted, each once, as floats. eq must have no symbol but x. Not exported.

    With domain = ℂ the complex roots too: for a polynomial (or a rational function) all of them; for another equation the real ones and the complex ones near the real axis that the rootfinder can vouch for (each polished on the equation itself), so complex roots far from the axis may be missing. An interval is for real roots only: it is not taken together with domain = ℂ.

    Polynomials are solved through their exact roots (correctly rounded real ones). Other equations are approximated on the interval by Chebyshev interpolants, piece by piece, and the roots of those checked against the equation: a feature narrower than the samples' spacing can be missed. The search stops at about 120 roots, those nearest the middle of the interval (the origin on the whole line), with a warning: tan(x) ~ x has infinitely many.

    @syms x
SymJ.fsolve(cos(x) ~ x, x)                       # [0.7390851332151607]
SymJ.fsolve(log(x) + sin(x) ~ 1, x, (0, 4))      # [1.1099…, 3.3530…]
SymJ.fsolve(x^5 - x + 1 ~ 0, x)                  # [-1.1673039782614187]
SymJ.fsolve(x^5 - x + 1 ~ 0, x; domain = ℂ)      # five roots

    SymJ.linear_eq_to_matrix — Tuple{Any, Any}

    source 
    SymJ.linear_eq_to_matrix(eqs, vars)

    The matrix form A x = b of linear equations: (A, b), A the Matrix{Sym} of the coefficients of vars (a row per equation, a column per unknown) and b the Vector{Sym} of the right sides, as SymPy's linear_eq_to_matrix. The equations are written with ~ (as for solve); an equation that is not linear in vars (an unknown in a denominator or inside a function, or a product of unknowns) is an error. Other symbols are parameters. Not exported.

    @syms x y a
A, b = SymJ.linear_eq_to_matrix([x + 2y ~ 3, a*x - y ~ 1], [x, y])
# A = [1 2; a -1], b = [3, 1]; A \ b solves it

    SymJ.SymSet

    source 
    SymSet

    A finite union of disjoint intervals with exact endpoints, sorted and merged; the solutions of an inequality (solve). Supports in, ∪, ∩, setdiff, ⊆, isempty; the intervals are S.intervals. Calling tests membership: S(2), or S(x => 2) for a set from solve(ineq, x) (which records its variable).

    SymJ.CylindricalSet

    source 
    CylindricalSet

    The solution of a system of linear inequalities in several unknowns, as nested bounds (a cylindrical description): the last unknown ranges over an interval, and each earlier one lies between bounds in the later ones; unknowns fixed by equations are given last. Not exported.

    Calling substitutes into the constraints it was solved from: C(x => 1, y => 4) is a Bool once every unknown has a value; with some unknowns given, C(y => 1) is the solution set in the others (a SymSet for one, a CylindricalSet for several). pt in C for a point given as a Dict is the same test.

    SymJ.SolutionSet

    source 
    SymJ.SolutionSet

    The set SymJ.solveset gives: the union of finitely many points, of the families in families (SymJ.ImageSet), and of the unsolved parts in unsolved (SymJ.ConditionSet). Supports in (for a family not linear in its variable, the variable solved for, or Lambert's branch found numerically: lambertw(1, -1) in {lambertw(1, n) | n ∈ ℤ}), isempty, ∩ with an interval set (a family linear in its variable cut to its finitely many members), and collect when it is finite. Not exported.

    SymJ.solveset — Tuple{Relation, Sym}

    source 
    SymJ.solveset(eq, x; domain = ℝ)

    Every solution of the equation eq in x, as a set (SymJ.SolutionSet): the real ones, or with domain = ℂ the complex ones. Where solve gives one period or a principal branch, solveset gives the families: sin(x) ~ 1//2 has {π/6 + 2πn : n ∈ ℤ} ∪ {5π/6 + 2πn : n ∈ ℤ}, and over ℂ, exp(x) ~ 2 has {log(2) + 2πin : n ∈ ℤ}. Nested functions are inverted in turn: sin(sin(x)) ~ 0 is sin(x) ∈ {πm}, which over ℝ is sin(x) = 0. An equation it cannot solve gives a SymJ.ConditionSet rather than an error, and an inequality gives solve's set. The bound variables are named n, m, k, … (skipping names in eq). Over ℝ, parameters are taken real and the answer comes by cases on them: sin(x) ~ a has the families for -1 ≤ a ≤ 1 and ∅ otherwise. Several trigonometric functions of one angle with a parameter go through one of them (tan(x) + cot(x) ~ a in tan(x)) or tan(x/2), the angle π decided apart (sin(x) + cos(x) ~ a: -√2 ≤ a ≤ √2, a ≠ -1, and a = -1). An equation through Lambert's W has every branch: over ℂ {W_k(a) : k ∈ ℤ} (shown lambertw(a, n)), over ℝ the real branches W₀ and, on [-1/e, 0), W₋₁. With Latexify loaded, the sets display as LaTeX. Not exported.

    SymJ.solveset(sin(x) ~ 1//2, x)              # {π/6 + 2πn} ∪ {5π/6 + 2πn}
SymJ.solveset(exp(x) ~ 2, x)                 # {log(2)}
SymJ.solveset(exp(x) ~ 2, x; domain = ℂ)     # {log(2) + 2πin}
SymJ.solveset(sin(x^2) ~ 0, x)               # {-√(πn), √(πn) : n ≥ 0}
S = SymJ.solveset(cos(x) ~ 0, x)
S ∩ solve([x ≧ 0, x ≦ 2PI], [x])             # {π/2, 3π/2}
SymJ.solveset(sin(x) ~ a, x)                 # a < -1 => ∅, -1 ≤ a ≤ 1 => {asin(a) + 2πn} ∪ …, a > 1 => ∅
SymJ.solveset(x*exp(x) ~ 1, x; domain = ℂ)   # {lambertw(1, n) | n ∈ ℤ}

    SymJ.ChebZeros.cheb_all_zeros — Tuple{Any}

    source 
    cheb_all_zeros(f, a, b; ctol=1e-6, polish=true, kwargs...)
cheb_all_zeros(f; kwargs...)        # whole real line

    Real zeros of f on [a, b] (as cheb_zeros; a and b may be infinite), plus the complex zeros of the Chebyshev proxy that can be trusted. Returns a named tuple (real, complex).

    complex holds the non-real zeros, each a named tuple (z, rho, errest, polished):

    • rho – Bernstein-ellipse parameter of the root for the piece it came from (1 = on the piece; larger = farther out)

    • errest – estimated |p - f| / max|f| there for the proxy p: ε·ρⁿ, with ε the relative size of the discarded Chebyshev coefficients and n the degree. A root is kept only if errest ≤ ctol. The root's own error is roughly errest·max|f| / |f′(z)|.

    • polished – true if complex secant steps on f converged. If f accepts complex input, roots that don't polish are dropped; if it doesn't, the proxy's roots are returned unpolished.

    Each piece has its own ellipse, so the trusted region is a union of ellipses hugging the real axis. Near-real conjugate pairs that are really a double real zero are dropped (that zero is in real).

    On an infinite interval the real zeros come from the mapped search, and complex zeros are looked for (on the finite interval) in a window around them: |x - c| ≤ R, with R = max(10·scale, 2·max|r - c|) over the real zeros r, and c the center (whole line) or the finite end (half-line).

    SymJ.ChebZeros.cheb_zeros — Tuple{Any}

    source 
    cheb_zeros(f, a, b; kwargs...)
cheb_zeros(f; kwargs...)             # whole real line, same as cheb_zeros(f, -Inf, Inf)

    Find all zeros of a continuous function f on [a, b] with a Chebyshev-proxy rootfinder. Returns a sorted vector.

    a and/or b may be infinite. Then the interval is mapped onto [-1, 1]:

    (-∞, ∞):  x = center + scale·t/(1-t²)
[a, ∞):   x = a + scale·(1+t)/(1-t)
(-∞, b]:  x = b - scale·(1-t)/(1+t)

    and f's values are squashed by y ↦ (y/σ)/√(1+(y/σ)²), σ a typical |f| from a few samples (same zeros and signs, but bounded). This works when f is "tame at infinity": it tends to a limit, or to ±∞ like a power or an exponential. If f oscillates forever (sin(x)) there are infinitely many zeros; you get those that could be resolved and a warning. scale (default 1) should be roughly the size of x where the action is. A zero far out is still found (and then polished to full accuracy in x), but at a cost in function evaluations.

    Keywords:

    • maxdeg – largest interpolant degree on a piece before it is split (128)

    • tol – relative size (vs. max|f| on the piece) below which coefficients count as zero

    • maxdepth – maximum number of subdivisions

    • maxzeros – stop once about this many zeros are found (120); with maxtotaldeg, a budget on the total degree of the piecewise polynomial proxy (5000) for an f that oscillates without crossing zero. When either runs out, the zeros nearest the middle (or the origin, or the finite end of a half-line) are returned, with a warning

    • imtol – how far from the real axis an eigenvalue may be and still be a candidate

    • ztol – for zeros without a sign change, accept if |f(x)| ≤ ztol·max|f|

    • plateau – coefficients that level off below plateau·max|f| count as noise (noisy f)

    • pairtol – unbracketed candidates closer than pairtol·w are one even-order zero (w = b - a, or its local equivalent under the map)

    • scale, center – the maps above (infinite intervals only)
