    SymQR

    The QR factorization of a matrix of expressions from qr: F.Q with orthonormal columns and F.R upper triangular, A == Q * R; Q, R = F destructures it. Not exported.

    Base.exp — Tuple{StridedMatrix{Sym}}

    source 
    exp(A::AbstractMatrix{Sym}), sin(A), cos(A)

    The matrix exponential (sine, cosine) of a square matrix of expressions, exactly, through its Jordan form. exp(t*A) solves x' = A x.

    exp(t * Sym[0 1; -1 0])          # [cos(t) sin(t); -sin(t) cos(t)]

    Base.inv — Tuple{StridedMatrix{Sym}}

    source 
    inv(A::AbstractMatrix{Sym})

    The inverse of a matrix of expressions, exactly, by Gauss–Jordan elimination over rational functions in the entries' atoms (exact rationals for numbers). A singular matrix throws a LinearAlgebra.SingularException.

    inv([a b; c d])                  # [d -b; -c a] / (a*d - b*c)

    LinearAlgebra.det — Tuple{AbstractMatrix{Sym}}

    source 
    det(A::AbstractMatrix{Sym})

    The determinant of a matrix of expressions, exactly: fraction-free (Bareiss) elimination when the entries are polynomials, Gaussian elimination over rational functions in the entries' atoms otherwise, pivoting on the first nonzero entry. The result is in lowest terms.

    det([a b; c d])                  # a*d - b*c
det([x 1; 1 x])                  # x^2 - 1

    LinearAlgebra.eigen — Tuple{AbstractMatrix{Sym}}

    eigen(A::AbstractMatrix{Sym})

    The eigenvalues and eigenvectors of a diagonalizable matrix of expressions, as a LinearAlgebra.Eigen (F.values, F.vectors, with A * F.vectors == F.vectors * Diagonal(F.values)). A defective matrix (too few eigenvectors) is an ArgumentError; eigvals and eigvecs still apply.

    LinearAlgebra.eigvals — Tuple{AbstractMatrix{Sym}}

    source 
    eigvals(A::AbstractMatrix{Sym})

    The eigenvalues of a matrix of expressions, each repeated by its algebraic multiplicity: the roots of the characteristic polynomial, exact where solve finds them exactly.

    eigvals(Sym[2 1; 1 2])       # [1, 3]
eigvals([a b; b a])          # [a - b, a + b]

    eigvecs(A::AbstractMatrix{Sym})

    Eigenvectors of a matrix of expressions as the columns of a matrix: a basis of each eigenspace, the null space of A - v*I, eigenvalue by eigenvalue (in the order of eigvals). A defective matrix has fewer columns than rows.

    LinearAlgebra.lu — Union{Tuple{AbstractMatrix{Sym}}, Tuple{AbstractMatrix{Sym}, Union{LinearAlgebra.NoPivot, LinearAlgebra.RowMaximum, LinearAlgebra.RowNonZero}}}

    source 
    lu(A::AbstractMatrix{Sym}; check = true)

    The LU factorization of a matrix of expressions, A[p, :] == L * U, as a LinearAlgebra.LU: computed exactly over rational functions in the entries' atoms, pivoting on the first nonzero entry of each column (there is no magnitude to compare). F.L, F.U, F.p, det(F) and F \ b work as usual. A singular matrix throws a LinearAlgebra.SingularException unless check = false; NoPivot() factors without row exchanges.

    LinearAlgebra.qr — Tuple{AbstractMatrix{Sym}}

    source 
    qr(A::AbstractMatrix{Sym})

    The (thin) QR factorization of a matrix of expressions with linearly independent columns, by Gram–Schmidt with exact arithmetic: Q has orthonormal columns (their norms are square roots), R is upper triangular with positive diagonal. Symbols are taken to be real in the inner product. Returns a SymJ.SymQR (F.Q, F.R, or Q, R = qr(A)).

    Q, R = qr(Sym[1 1; 1 0])          # Q = [1 1; 1 -1]/sqrt(2), R = [sqrt(2) 1/sqrt(2); 0 1/sqrt(2)]

    LinearAlgebra.svd — Tuple{AbstractMatrix{Sym}}

    source 
    svd(A::AbstractMatrix{Sym}; full = false)
svdvals(A::AbstractMatrix{Sym})

    The singular value decomposition of a matrix of expressions, exactly, as a LinearAlgebra.SVD (F.U, F.S, F.Vt, or U, S, V = svd(A)), with A == F.U * Diagonal(F.S) * F.Vt. The singular values are the square roots of the eigenvalues of A'A (largest first when they are numbers), the columns of V orthonormal eigenvectors of A'A, and those of U are A v / σ. As for svd on numbers, U and V have min(m, n) columns, completed (for zero singular values) by orthonormal bases of the null spaces; with full = true, U and V are square. Symbols are taken to be real in A'A. A singular value with a symbol, such as sqrt(a^2), is refined under the assumptions (assume, or an assuming block): a for a > 0, abs(a) for real a, and left as it is otherwise. The roots of the characteristic polynomial of A'A must be found, and nested square roots are common, so this is for small matrices.

    F = svd(Sym[3 0; 4 5])           # F.S == [3*sqrt(5), sqrt(5)]
svdvals(Sym[1 1; 0 0])           # [sqrt(2), 0]
svdvals(Sym[a 0; 0 b])           # [sqrt(b^2), sqrt(a^2)]
svdvals(Sym[a 0; 0 b]; assume = @assume(a > 0, b > 0))   # [b, a]

    SymJ.jordan_form — Tuple{AbstractMatrix}

    source 
    SymJ.jordan_form(A)

    (P, J) with A == P * J * inv(P) and J the Jordan form of the square matrix of expressions A: a block for each Jordan chain, the eigenvalue on the diagonal and ones above it. The chains are built from the kernels of (A - λI)^k, exactly. Not exported.

    P, J = SymJ.jordan_form(Sym[1 1; 0 1])     # J = [1 1; 0 1]

    SymJ.rref — Tuple{AbstractMatrix}

    source 
    SymJ.rref(A::AbstractMatrix)

    The reduced row echelon form of a matrix of expressions, exactly. As for linear systems, a symbolic pivot is taken to be nonzero (the generic case): rref([a 1; 1 1]) divides by a - 1. Not exported (it is not a LinearAlgebra function).

    SymJ.rref(Sym[1 2 3; 4 5 6; 7 8 9])     # [1 0 -1; 0 1 2; 0 0 0]
