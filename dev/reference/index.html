    SymJ.SymJ

    source 
    SymJ

    Symbolic manipulation with a single concrete, hash-carrying node type, eager canonicalization of sums, products and powers, exact numbers, and support for the TermInterface v2 contract. See docs/src/design.md for the design.

    SymJ.AbstractSymbolic

    source 
    AbstractSymbolic <: Function

    Supertype of SymJ's symbolic objects. Symbolic objects are callable, and calling a SymFunction builds an unevaluated function application. An expression ex can be called in these ways:

    • ex(a) with a number a: evaluates ex, which may have one free variable, with Julia's arithmetic on a (see evaluate), so (x^2)(3) === 9. With a symbolic a, it substitutes instead.

    • ex(x => a, y => b): substitutes (see subs) and returns an expression.

    • ex(; x = a, y = b): gives values to the variables named x and y. If every one of ex's variables gets a non-symbolic value, ex is evaluated with Julia arithmetic and the result is a Julia number: (x^2 + y)(; x = 2, y = 3) === 7. Otherwise this substitutes and returns an expression: (x^2 + y)(; x = 2) == y + 4. Names that are not in ex are ignored, so one set of keywords can be used for several expressions. Keywords can't be combined with the other forms.

    • ex(): the value of a constant expression as a Julia number, or ex itself if it has a free variable.

    SymJ.Assumptions

    source 
    Assumptions(facts...)

    Facts about symbols, normalized once so that operations taking them (assume = A, or assuming) can reuse the work. A fact is:

    • a relation: x ≫ 0, a ≦ b + 1, x ~ 2, a ≶ 0 (≠). An order relation makes the symbols in it real.

    • membership in a number set: n ∈ ℤ, x ∈ ℝ, x ∉ ℤ (ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ). Symbols are complex unless a fact says otherwise.

    • a combination: f & g; f | g and !f for facts about one symbol (!(0 ≦ x) | (x ≫ 1)); ! on a single relation or membership.

    Several facts (or a vector of them) are all assumed. Relations among several symbols are used as linear relations, a nonlinear monomial such as a*b taken as a quantity of its own. Contradictory facts throw an ArgumentError. Assumptions(A, facts...) adds facts to A.

    A = Assumptions(x ≫ 0, n ∈ ℤ, a ≦ b)

    SymJ.Cases

    source 
    Cases

    The answer of an operation that depends on facts the assumptions do not decide: a vector of conditions => answer pairs, the conditions a vector of facts that all hold in that case. Not exported.

    Calling it with values for the symbols in the conditions, cs(a => 2), gives the answer for those values; indexing with them, cs[a => 2], gives their case.

    cs = solve(x^2 ~ a, x; assume = (x ≫ 0,))
cs[1]          # [a ≫ 0] => [sqrt(a)]
cs(a => 4)     # [2]

    SymJ.CylindricalSet

    source 
    CylindricalSet

    The solution of a system of linear inequalities in several unknowns, as nested bounds (a cylindrical description): the last unknown ranges over an interval, and each earlier one lies between bounds in the later ones; unknowns fixed by equations are given last. Not exported.

    Calling substitutes into the constraints it was solved from: C(x => 1, y => 4) is a Bool once every unknown has a value; with some unknowns given, C(y => 1) is the solution set in the others (a SymSet for one, a CylindricalSet for several). pt in C for a point given as a Dict is the same test.

    SymJ.NumberSet

    source 
    NumberSet

    One of the number sets ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ, also named Integers, Rationals, Reals and Complexes, for facts such as n ∈ ℤ (or n in Integers) in Assumptions. On a number, ∈ is a Bool (2 ∈ ℤ); on a symbol it is a fact.

    SymJ.Poly

    source 
    Poly{C}

    Sparse multivariate polynomial in the generators gens(p) with coefficients of type C: SymNumber for numeric coefficients, or Sym for symbolic ones. Terms are stored in lex order with gens(p)[1] most significant.

    Poly(ex, x, y, ...)

    Convert the expression ex to a polynomial in x, y, .... Coefficients are SymNumber when they are all numeric, and Sym otherwise (so Poly(a*x^2 + b, x) has coefficients a and b). Use Poly{C}(ex, x, ...) to choose the coefficient type. Sym(p) converts back. Degrees and the number of generators are unlimited; polynomials whose exponents fit in 64 bits (64 ÷ ngens bits each) are the fast case, and larger ones are packed into wider words. Arithmetic on polynomials keeps their packing: p * q or p^k whose exponents do not fit throws an error, while Poly, gcd, factor and the functions on expressions widen and carry on.

    SymJ.Relation

    source 
    Relation

    A symbolic equation or inequality between two expressions: x^2 + 1 ~ 3, x ≪ 1 (Lt(x, 1)), x ≦ 1, x ≫ 1, x ≧ 1, x ≶ 1 (Ne). See lhs, rhs.

    Calling a relation substitutes into both sides, as calling an expression does ((x^2 ~ 4)(x => 2), (x^2 ~ 4)(2)); when no symbols remain the result is a Bool. r() evaluates a relation between constants.

    SymJ.Rule

    source 
    SymJ.Rule

    A rewrite rule, made by SymJ.@rule or SymJ.rule. Called on an expression, it gives the rewritten expression, or nothing when the left side doesn't match (or every match's right side is nothing).

    SymJ.Sym

    source 
    Sym

    A symbolic expression. Construct leaves with Sym(:x), Sym(2), Sym(1//3), Sym(π), or the @syms macro; build compound expressions with the usual arithmetic operators and functions. Expressions are kept in a canonical form as they are built: like terms are collected in sums, like bases are collected in products, and numeric powers such as sqrt(Sym(8)) are reduced exactly (to 2*sqrt(2)).

    Layout by kind:

    kind num args exps coefs
    NUMBER the value
    SYMBOL
    CONSTANT
    ADD constant term terms (sorted) coefficient of each
    MUL coefficient bases (sorted) exponent of each
    POW [base, exponent]
    FN arguments

    name holds the symbol, constant, or function name. The vectors must never be mutated once a node is built; nodes share them freely.

    SymJ.SymNumber

    source 
    SymNumber <: Real

    Numeric scalar used inside symbolic expressions. It is exact (an integer or rational of arbitrary size) unless constructed from a floating point value. Small values never allocate; arithmetic promotes to BigInt on overflow and demotes back when results fit.

    SymJ.SymQR

    source 
    SymQR

    The QR factorization of a matrix of expressions from qr: F.Q with orthonormal columns and F.R upper triangular, A == Q * R; Q, R = F destructures it. Not exported.

    SymJ.SymSeries

    source 
    SymSeries

    A truncated series in x about x0: Σ cᵢ (x - x0)^eᵢ + O((x - x0)^n), or in 1/x at x0 = ±Inf. Returned by series. Sym(s) is the truncated expression (the O term dropped); calling s calls that expression. Series about the same point add, subtract, multiply, divide and take powers, with the order of the error tracked, and diff(s, x) differentiates term by term. Not exported.

    SymJ.SymSet

    source 
    SymSet

    A finite union of disjoint intervals with exact endpoints, sorted and merged; the solutions of an inequality (solve). Supports in, ∪, ∩, setdiff, isempty; the intervals are S.intervals. Calling tests membership: S(2), or S(x => 2) for a set from solve(ineq, x) (which records its variable).

    Base.diff — Union{Tuple{Sym, Sym}, Tuple{Sym, Sym, Integer}}

    source 
    diff(ex::Sym, x::Sym, n=1)
diff(ex::Sym, x::Sym, y::Sym, zs::Sym...)

    Derivative of ex with respect to the symbol x, n times. With several symbols, the mixed derivative: ex differentiated with respect to x, then y, then each of zs, so diff(ex, x, y) is ∂²ex/∂y∂x and diff(ex, x, x, y) is ∂³ex/∂y∂x².

    Functions without a registered derivative rule give an unevaluated Derivative(f(...), x).

    diff(x^3 * y^2, x, 2)        # 6*x*y^2
diff(x^3 * y^2, x, y)        # 6*x^2*y
diff(sin(x * y), x, y)       # -x*y*sin(x*y) + cos(x*y)

    Base.divrem — Union{Tuple{C}, Tuple{Poly{C}, Poly{C}}} where C

    source 
    divrem(p::Poly, q::Poly)

    Quotient and remainder of multivariate division of p by q in lex order (generators most significant first): p == quo*q + rem, and no term of rem is divisible by the leading monomial of q. For univariate polynomials this is ordinary long division. Coefficients are divided exactly, so integer polynomials may give rational results.

    CommonSolve.solve — Tuple{AbstractVector{<:Relation}, Union{Tuple, AbstractVector}}

    source 
    solve(eqs::AbstractVector{<:Relation}, vars)

    Solve a system of equations (written with ~) for the variables vars. The result is a vector of solutions, each a Dict with every one of vars as a key; an inconsistent system gives an empty vector. Both arguments must be vectors (or tuples): one equation in one unknown is solve(eq, x), which gives a vector of values instead.

    • Linear systems are solved by Gauss–Jordan elimination. An underdetermined system has one solution, with the pivot variables given in terms of the free ones, which map to themselves.

    • Polynomial (and rational) systems are solved through a lex Gröbner basis (groebner), which is triangular, by back-substitution. The values are exact where the equations in one variable along the way can be solved exactly, numeric otherwise. With infinitely many solutions, the variables left free map to themselves.

    Coefficients may involve other symbols; the solutions are then the generic ones (for example, assuming a ≠ 0 in a*x + y ~ 1).

    solve([x + y ~ 3, x - y ~ 1], [x, y])          # [Dict(x => 2, y => 1)]
solve([x + y + z ~ 1, x - z ~ 0], [x, y, z])    # [Dict(x => z, y => 1 - 2z, z => z)]
solve([x^2 + y^2 ~ 1, x ~ y], [x, y])          # [Dict(x => -√2/2, y => -√2/2), Dict(x => √2/2, y => √2/2)]
solve([x*y ~ 1, x + y ~ 3], [x, y])

    CommonSolve.solve — Tuple{Relation, Sym}

    source 
    solve(eq::Relation, x; assume = nothing)

    The solutions of the equation eq (written with ~, e.g. x^2 ~ 4) for x, as a vector of distinct expressions. The equation must be polynomial or rational in x; its coefficients may involve other symbols. Solutions are exact through degree 4 and for equations that factor into such pieces; irreducible factors of higher degree with numeric coefficients give numeric (floating point) roots. Numeric solutions are sorted, real ones first. An equation with no solution gives an empty vector. For a system, solve([eqs...], [vars...]), giving a vector of Dicts; mixing the forms (solve(eq, [x]), solve([eq], x)) is an error.

    solve(x^2 - 2 ~ 0, x)          # [-sqrt(2), sqrt(2)]
solve(x^2 ~ -1, x)             # [-im, im]
solve(a*x + b ~ 0, x)          # [-b/a]

    With assumptions (assume = (x ≫ 0,), an Assumptions, or inside assuming), only the solutions they allow for x are kept: those in its number set (x ∈ ℝ), its range (x ≫ 0), and consistent with its relations to other symbols. Facts about the other symbols are used to decide that. When the answer depends on something the assumptions leave open, the result is a Cases value: a list of conditions => solutions, which can be called with values (cs(a => 4)).

    solve(x^2 ~ 4, x; assume = (x ≫ 0,))                # [2]
solve(x^2 ~ a, x; assume = (x ∈ ℝ, a ∈ ℝ))         # a < 0 => [], a == 0 => [0], a > 0 => [-√a, √a]
solve(x^2 ~ a, x; assume = (x ≫ 0,))                # a > 0 => [√a], !(a > 0) => []

    LinearAlgebra.det — Tuple{AbstractMatrix{Sym}}

    source 
    det(A::AbstractMatrix{Sym})

    The determinant of a matrix of expressions, exactly: fraction-free (Bareiss) elimination when the entries are polynomials, Gaussian elimination over rational functions in the entries' atoms otherwise, pivoting on the first nonzero entry. The result is in lowest terms.

    det([a b; c d])                  # a*d - b*c
det([x 1; 1 x])                  # x^2 - 1

    LinearAlgebra.eigen — Tuple{AbstractMatrix{Sym}}

    source 
    eigen(A::AbstractMatrix{Sym})

    The eigenvalues and eigenvectors of a diagonalizable matrix of expressions, as a LinearAlgebra.Eigen (F.values, F.vectors, with A * F.vectors == F.vectors * Diagonal(F.values)). A defective matrix (too few eigenvectors) is an ArgumentError; eigvals and eigvecs still apply.

    LinearAlgebra.eigvals — Tuple{AbstractMatrix{Sym}}

    source 
    eigvals(A::AbstractMatrix{Sym})

    eigvals(Sym[2 1; 1 2])       # [1, 3]
eigvals([a b; b a])          # [a - b, a + b]

    LinearAlgebra.lu — Union{Tuple{AbstractMatrix{Sym}}, Tuple{AbstractMatrix{Sym}, Union{LinearAlgebra.NoPivot, LinearAlgebra.RowMaximum, LinearAlgebra.RowNonZero}}}

    LinearAlgebra.qr — Tuple{AbstractMatrix{Sym}}

    source 
    qr(A::AbstractMatrix{Sym})

    The (thin) QR factorization of a matrix of expressions with linearly independent columns, by Gram–Schmidt with exact arithmetic: Q has orthonormal columns (their norms are square roots), R is upper triangular with positive diagonal. Symbols are taken to be real in the inner product. Returns a SymJ.SymQR (F.Q, F.R, or Q, R = qr(A)).

    Q, R = qr(Sym[1 1; 1 0])          # Q = [1 1; 1 -1]/sqrt(2), R = [sqrt(2) 1/sqrt(2); 0 1/sqrt(2)]

    SymJ._check_gcd_method — Tuple{Symbol}

    source 
    gcd(p::Poly, q::Poly; method = :auto)

    Greatest common divisor of polynomials with numeric (exact) coefficients. For integer inputs the result is the integer gcd, including the gcd of the integer contents, with a positive leading coefficient. If either input has non-integer rational coefficients, the result is monic.

    The method is Brown's modular algorithm (method = :dense), or that with Zippel's sparse interpolation (method = :zippel): much faster when the inputs have few terms relative to their degrees, as with many variables, and slower when they are dense. The default method = :auto chooses between them by estimating the dense cost. The result is the same either way (it is verified by division).

    SymJ.apart — Tuple{Sym, Sym}

    source 
    apart(ex, x; gcd_method = :auto)
apart(ex; gcd_method = :auto)

    Partial fraction decomposition of a rational function of x with exact coefficients: a polynomial plus terms c(x)/p(x)^j, p irreducible and deg c < deg p. Coefficients may involve other symbols (and, as in cancel, function applications): the decomposition is then over the field of rational functions in them, ℚ(a, b, ...). With no x, ex must have one free variable. gcd_method (:auto, :dense or :zippel; see gcd) chooses the gcd method in the initial cancel and in factoring the denominator.

    apart(1/(x^2 - 1))              # 1/(2*(x - 1)) - 1/(2*(x + 1))
apart((x^3 + 1)/(x^2 - 1))      # x + 1/(x - 1)
apart(1/((x - a)*(x - b)), x)   # 1/((a - b)*(x - a)) - 1/((a - b)*(x - b))

    SymJ.assuming — Tuple{Any, Vararg{Any}}

    source 
    assuming(f, facts...)
assuming(facts...) do … end

    Run f with the facts assumed by the operations that take assumptions, as if each were given assume = …. Blocks nest: an inner block adds its facts to the outer ones, and so does an assume keyword inside a block. The facts are normalized once, when the block starts (Assumptions).

end

    SymJ.cancel — Tuple{Sym}

    source 
    cancel(ex; gcd_method = :auto)

    Write ex as p/q with p and q expanded polynomials that have no common factor. q has a positive leading coefficient and the integer content is shared out, so a polynomial input comes back expanded.

    Symbols, function applications such as sin(x), and non-integer powers such as sqrt(x) are treated as independent variables. This is always valid, but relations among them are not used: (x - 1)/(sqrt(x) - 1) is not reduced to sqrt(x) + 1. The exception is square roots of rational numbers, whose squares are known: a common factor through them is cancelled, as in cancel((x^2 + 2sqrt(2)x + 2)/(x + sqrt(2))) == x + sqrt(2). Expressions with floating point coefficients are returned unchanged. gcd_method (:auto, :dense or :zippel; see gcd) chooses the gcd method.

    cancel((x^2 - 1)/(x + 1))                  # x - 1
cancel(1/x + 1/x^2)                        # (x + 1)/x^2
cancel((sin(x)^2 - 1)/(sin(x) + 1))        # sin(x) - 1

    SymJ.dsolve — Tuple{Relation, Sym, Vararg{Pair}}

    source 
    SymJ.dsolve(eq, y(x), ics...)

    Solve the ordinary differential equation eq (an equation, written with ~) for the function y(x). Derivatives are written diff(y(x), x) or y'(x). The result is an equation: y(x) ~ S with constants C1, C2, … (one for each order), or an implicit solution φ(x, y(x)) ~ C1 when y cannot be solved for.

    Initial conditions are pairs, one for each order: y(0) => 1, y'(0) => 0. They fix the constants.

    Methods: first order linear, separable, Bernoulli, exact (with an integrating factor in x or y alone), homogeneous; linear with constant coefficients, of any order (undetermined coefficients, else variation of parameters, for the right side); Cauchy–Euler; equations without y (reduced to a lower order). Integrals are done by the RischIntegrate extension when it is loaded (an unevaluated Integral otherwise, or when there is no elementary antiderivative).

    Not exported.

    @syms x y()
SymJ.dsolve(y'(x) ~ y(x), y(x))                          # y(x) ~ C1*exp(x)
SymJ.dsolve(y''(x) + y(x) ~ 0, y(x), y(0) => 0, y'(0) => 1)   # y(x) ~ sin(x)
SymJ.dsolve(y'(x) ~ x * y(x)^2, y(x))                    # y(x) ~ -2/(x^2 + 2C1)
SymJ.dsolve(x^2 * y''(x) - 2y(x) ~ 0, y(x))              # y(x) ~ C1/x + C2*x^2

    SymJ.evaluate — Tuple{Sym, Any}

    source 
    evaluate(ex, a)

    Evaluate ex, which may have at most one free symbol, at a using Julia arithmetic on a. This is what calling an expression on a non-symbolic value does: if u = x^2 then u(3) === 9, u(3.0) === 9.0 and u(1//2) === 1//4. Because the arithmetic is generic, a may be any number type (big floats, dual numbers, intervals, ...).

    • Exact coefficients are used as Julia integers and rationals, so exact inputs give exact results where Julia arithmetic would ((x/3)(3) == 1//1).

    • When a is a floating point type (real or complex), constants such as 1/3, sqrt(2) and π are computed in that type, so BigFloat inputs keep their precision.

    • Negative integer powers use inv ((1/x)(2) === 0.5), and a negative base with a fractional power gives the principal complex value (sqrt(x)(-4) == 2im).

    • Functions need a Julia method (registered with julia = ...); user functions without one throw an ArgumentError.

    SymJ.factor — Tuple{Poly{SymNumber}}

    source 
    factor(p::Poly; gcd_method = :auto) -> (unit, [f₁ => m₁, f₂ => m₂, ...])
factor(ex::Sym; gcd_method = :auto)

    Factorization into irreducibles over the rationals: p == unit * Π fᵢ^mᵢ with each fᵢ irreducible, primitive, of positive leading coefficient. Factors are sorted by multiplicity, then degree. Coefficients must be exact.

    For an expression the result is the factored expression; rational expressions are reduced with cancel and their numerator and denominator factored, and, as in cancel, function applications and non-integer powers are treated as variables:

    factor(x^4 - 1)                 # (x - 1)*(x + 1)*(x^2 + 1)
factor(x^2*y^2 - 1)             # (x*y - 1)*(x*y + 1)

    gcd_method (:auto, :dense or :zippel; see gcd) chooses the method for the gcds of the squarefree decomposition and, for expressions, of cancel.

    Multivariate inputs are factored through Kronecker substitution, whose cost grows with the product of the degrees in each variable; very large inputs throw an ArgumentError rather than run for a long time.

    SymJ.factor_squarefree — Tuple{Poly{SymNumber}}

    source 
    factor_squarefree(p::Poly) -> (unit, [f₁ => 1, f₂ => 2, ...])
factor_squarefree(ex::Sym)

    Squarefree factorization: p == unit * f₁^m₁ * f₂^m₂ * ... with the fᵢ squarefree, pairwise coprime, of positive leading coefficient and integer content 1, and the multiplicities mᵢ distinct and increasing. Coefficients must be exact.

    For an expression, the result is the expression unit * f₁^m₁ * .... Rational expressions are first reduced with cancel, and their numerator and denominator are factored. As in cancel, function applications and non-integer powers are treated as independent variables:

    factor_squarefree(x^3 - x^2 - x + 1)               # (x + 1)*(x - 1)^2
factor_squarefree((x^2 - 1)/(x^2 + 2x + 1)^2)      # (x - 1)/(x + 1)^3

    SymJ.groebner — Tuple{AbstractVector, Vararg{Sym}}

    source 
    groebner(polys, vars...; order = :lex)

    The reduced Gröbner basis of the ideal generated by polys (expressions, or equations lhs ~ rhs, taken as lhs - rhs), in the variables vars (most significant first; all the symbols, in alphabetical order, if none are given), as a vector of expressions with leading coefficient 1, by decreasing leading monomial.

    order is :lex, :grlex or :grevlex. A lex basis is triangular: its last polynomials involve only the last variables, which is how it eliminates variables and solves systems. When the system has finitely many solutions, a lex basis is computed as a grevlex one, usually much cheaper, then converted (FGLM).

    Other symbols are parameters: the basis is over rational functions in them, right for generic values of the parameters, which may fail at special values.

    The basis is [1] exactly when the polynomials have no common zero, over the complex numbers.

    groebner([x^2 + y^2 - 1, x - y], x, y)       # [x - y, y^2 - 1/2]
groebner([x*y - 1, x^2 + y^2 - 4], x, y; order = :grevlex)
groebner([x^2 + y^2 - r^2, x - y], x, y)     # [x - y, y^2 - r^2/2]

    See also reduced.

    SymJ.limit — Tuple{Any, Pair}

    source 
    limit(f, x => x0; dir = :both, assume = nothing)

    The limit of f as x tends to x0: a number, an expression, or ±Inf. The limit is two-sided unless dir is :+ (from above) or :- (from below). Computed by Gruntz's algorithm (GruntzLimit), which handles exponentials and logarithms that cancel in ways numerical evaluation cannot follow.

limit(1 / x, x => 0; dir = :+)               # Inf

limit(x^a, x => Inf; assume = @assume(a > 1))   # Inf

    SymJ.pattern — Tuple{Any}

    source 
    SymJ.pattern(ex)

    A pattern from the expression ex, usually quoted, in which ~x marks a slot:

    Slot In a function's arguments In a sum or product
    ~x one argument one or more terms (factors), bound to their sum (product)
    ~!x one argument any number; none gives 0 (1)
    ~~x any number, bound to a vector any number; none gives 0 (1)
    ~~~x one or more, bound to a vector one or more

    In an exponent, ~!n is 1 when there is no power.     The pattern is put in canonical form, as any expression is (~x + ~x is 2*~x, exp(log(~x)) is ~x), and means what that form means. A number divides into a slot: ~x - ~y matches a - 2b with y => 2b.

    p = SymJ.pattern(:(~!a * sin(~x) + ~~r))
match(p, 3sin(t) + 1)          # Dict(:a => 3, :x => t, :r => 1)
eachmatch(SymJ.pattern(:(~x + ~y)), a + b + c)   # six matches
occursin(SymJ.pattern(:(sin(~x)^2)), 1 + sin(t)^2)   # true

    Not exported.

    SymJ.refine — Tuple{Any}

    source 
    refine(ex; assume = nothing)

    ex with the identities applied that hold under the assumptions (assume, or an assuming block; see Assumptions):

    • sqrt(x^2) = abs(x) for real x, abs(x) = x for x ≥ 0 (-x for x ≤ 0), and sign(x) when the sign is known;

    • (x^a)^b = x^(a*b) for x ≥ 0, exp(u)^b = exp(b*u) for real u, and abs(x)^2 = x^2 for real x;

    • log(exp(u)) = u for real u, log(x^p) = p*log(x) for x > 0;

    • real, imag, conj, angle and abs from the real and imaginary parts the assumptions give (real(x) = x and conj(x) = x for real x, real(exp(im*x)) = cos(x), abs(x + im*y) = sqrt(x^2 + y^2) for real x, y);

    • (-1)^n = ±1 for an integer n of known parity, sin, cos, tan of u + n*π for an integer n (sin(n*π) = 0), and floor(n) = ceil(n) = n;

    • equalities in the assumptions are substituted.

    A relation is refined on both sides and is true or false when the assumptions decide it. Symbols are complex unless the assumptions say otherwise, so without them only the identities that hold for complex numbers apply.

    refine(sqrt(x^2); assume = @assume(x > 0))      # x
refine(sqrt(x^2); assume = @assume(x in Reals)) # abs(x)
refine(sin(x + 2n*π); assume = @assume(n in Integers))   # sin(x)
refine(x > 0; assume = @assume(x > 1))          # true

    SymJ.simplify — Tuple{Any}

    source 
    simplify(ex; assume = nothing)

    A simpler form of ex, by the number of nodes in the expression tree: ex is refined (see refine), its function arguments simplified, and then several transformations are tried and the smallest result kept (ex itself if none is smaller):

    • rational functions over a common denominator, in lowest terms;

    • powers: radicals of numbers combined (sqrt(2)*sqrt(3) = sqrt(6)), and of nonnegative quantities (sqrt(x)*sqrt(y) = sqrt(x*y) for x, y ≥ 0);

    • trigonometric identities: a normal form modulo sin^2 + cos^2 = 1, multiple angles and sums of angles (2sin(x)cos(x) = sin(2x), sin(x)cos(y) + cos(x)sin(y) = sin(x + y)), exponentials of imaginary arguments (cos(x) + im*sin(x) = exp(im*x));

    • hyperbolic identities, likewise, with exponentials (cosh(x)^2 - sinh(x)^2 = 1, exp(x) + exp(-x) = 2cosh(x));

    • logarithms combined or expanded where their arguments are positive (log(2) + log(3) = log(6));

    • radicals denested (sqrt(3 + 2sqrt(2)) = 1 + sqrt(2)), denominators rationalized (1/(1 + sqrt(2)) = sqrt(2) - 1), radicands factored (sqrt(x^2 + 2x + 1));

    • expansion and factoring.

    The transformations are also available on their own, unexported: SymJ.simplify_rational, SymJ.simplify_powers, SymJ.simplify_trig, SymJ.simplify_hyperbolic, SymJ.simplify_log and SymJ.simplify_radicals. Assumptions are given as for refine.

    simplify((x^2 - 1) / (x - 1))                    # x + 1
simplify((x + 1)^2 - x^2)                        # 2x + 1
simplify(sqrt(Sym(2)) * sqrt(Sym(3)))            # sqrt(6)
simplify(sqrt(x^2) / x; assume = @assume(x > 0)) # 1
simplify(1 - cos(x)^2)                           # sin(x)^2

    SymJ.simplify_hyperbolic(ex)

    ex with its hyperbolic functions and exponentials simplified, as SymJ.simplify_trig does for trigonometric ones: polynomials in sinh and cosh of base arguments reduced modulo cosh^2 - sinh^2 = 1, linearized, or written in exponentials, whichever is smallest (cosh(x)^2 - sinh(x)^2 = 1, 2sinh(x)cosh(x) = sinh(2x), cosh(x) + sinh(x) = exp(x), exp(x) + exp(-x) = 2cosh(x)). Not exported; used by simplify.

    SymJ.simplify_log — Tuple{Any}

    source 
    SymJ.simplify_log(ex; assume = nothing)

    ex with its logarithms combined or expanded, whichever is smaller:

    • combined, c₁ log(u₁) + c₂ log(u₂) = log(u₁^c₁ u₂^c₂) for uᵢ > 0 and real cᵢ (log(2) + log(3) = log(6); positive numbers need no assumptions);

    • expanded, log(a*b) = log(a) + log(b) for a > 0 (a positive factor does not change the argument of the product, so b may be anything), log(a^p) = p*log(a) for a > 0 and real p.

    Not exported; used by simplify.

    SymJ.simplify_powers — Tuple{Any}

    source 
    SymJ.simplify_powers(ex; assume = nothing)

    ex with powers combined: radicals of positive numbers with the same exponent multiply into one (sqrt(2)*sqrt(3) = sqrt(6), 2^(1/3)*4^(1/3) = 2), and so do powers of quantities known to be nonnegative (sqrt(x)*sqrt(y) = sqrt(x*y) for x, y ≥ 0); nested powers are taken apart as refine does. Not exported; used by simplify.

    SymJ.simplify_radicals — Tuple{Any}

    source 
    SymJ.simplify_radicals(ex; assume = nothing)

    ex with radicals simplified:

    • denested: sqrt(a + b*sqrt(c)) = sqrt(x) + sqrt(y) when a^2 - b^2 c is the square of a rational (sqrt(3 + 2sqrt(2)) = 1 + sqrt(2));

    • denominators rationalized: 1/(a + b*sqrt(c)) multiplied by the conjugate (1/(1 + sqrt(2)) = sqrt(2) - 1);

    • radicands factored, so that a power under a root comes out as refine allows (sqrt(x^2 + 2x + 1) = abs(x + 1) for real x, x + 1 for x ≥ -1).

    Not exported; used by simplify.

    SymJ.simplify_trig — Tuple{Any}

    source 
    SymJ.simplify_trig(ex)

    ex with its trigonometric functions simplified. The arguments are grouped into base angles (2x and x share the base x); sin and cos of multiples of a base are written as polynomials in S = sin(g) and C = cos(g), and tan, cot, sec, csc through them, as are exponentials of imaginary multiples (exp(i*x) = cos(x) + i*sin(x)). The resulting rational function is reduced modulo S^2 + C^2 = 1 (once eliminating S^2, once C^2) and cancelled, which is a normal form: an expression equal to zero by trigonometric identities becomes 0. The products are also linearized into sines and cosines of multiples of the base (2*sin(x)*cos(x) is sin(2x)), and written in exponentials. The smallest candidate is returned, with sin/cos written as tan. Not exported; used by simplify.

    SymJ.simplify_trig(sin(x)^2 + cos(x)^2)          # 1
SymJ.simplify_trig(1 - cos(x)^2)                 # sin(x)^2
SymJ.simplify_trig(2*sin(x)*cos(x))              # sin(2x)
SymJ.simplify_trig((exp(im*x) + exp(-im*x)) / 2) # cos(x)

    SymJ.summation — Tuple{Any, Sym, Any, Any}

    source 
    SymJ.summation(f, k, a, b; assume = nothing)

    The sum of f over the integers k = a, a+1, ..., b, in closed form where one is found. b may be Inf (an infinite series, whose value is found as a limit, so it may be Inf, or by cases of a parameter); a and b may be expressions. Assumptions about the other symbols are given with assume, as for limit.

    Polynomials in k are summed by Faulhaber's formula, hypergeometric terms (polynomials times r^k, factorials, binomials, rational functions that telescope) by Gosper's algorithm, and other rational functions through partial fractions, as harmonic numbers and polygamma functions (exact zeta values for even powers). A sum with no closed form is returned unevaluated, Sum(f, k, a, b). Not exported.

    SymJ.summation(k^2, k, 1, n)            # n^3/3 + n^2/2 + n/6
SymJ.summation(r^k, k, 0, n)            # (r^(n + 1) - 1)/(r - 1)
SymJ.summation(1/(k*(k + 1)), k, 1, Inf)  # 1
SymJ.summation(1/k^2, k, 1, Inf)        # π^2/6

    SymJ.@assume — Tuple

    source 
    @assume(facts...)

    Assumptions from facts written with Julia's own operators: <, <=, >, >=, ==, != (and ≤, ≥, ≠) make relations, chained comparisons such as 1 < y <= 2 are split into their parts, and &&, || and ! combine facts. Anything else is used as it is, such as n in Integers or a fact made earlier.

    A = @assume(x > 0 && 1 < y <= 2, n in Integers, a != 0)
solve(x^2 ~ 4, x; assume = @assume(x > 0))
assuming(@assume(x >= 1)) do … end

    SymJ.@assuming — Tuple

    source 
    @assuming facts... begin … end
@assuming(facts..., begin … end)

    Run the block with the facts assumed, the facts written as in @assume; assuming(@assume(facts...)) do … end in one step. The block's value is returned; as with do, the block is a function body, so variables assigned in it are local to it.

    @assuming x > 0 begin
    solve(x^2 ~ 4, x)       # [2]
end

    SymJ.@pattern — Tuple{Any}

    source 
    SymJ.@pattern ex

    The pattern SymJ.pattern makes from ex, written without quoting. The slots' predicates are evaluated where the macro is called, and $v puts in the value of v; other names are symbols (a in a pattern is Sym(:a)). Not exported.

    isodd3(n) = isodd(n) && n > 3
p = SymJ.@pattern (~x)^(~n::isodd3)
c = sin(t)
q = SymJ.@pattern ~x + $c

    SymJ.@rule — Tuple{Any}

    source 
    SymJ.@rule lhs => rhs

    A rewrite rule: when the pattern lhs (as for SymJ.@pattern) matches, the result is rhs, Julia code run where the macro is called with ~x the value bound to the slot ~x. A right side that gives nothing rejects the match, and the search goes on to the next. Use with SymJ.rewrite or replace, or call the rule on an expression. Not exported.

    r = SymJ.@rule sin(~x)^2 + cos(~x)^2 + ~~r => 1 + ~r
r(sin(t)^2 + cos(t)^2 + a)               # 1 + a
SymJ.@rule log(~x * ~y) => log(~x) + log(~y)
SymJ.@rule ~x^(~n::isinteger) => ~n * ~x^(~n - 1)
SymJ.@rule (~f)(~x + 2π) => (~f in (sin, cos) ? (~f)(~x) : nothing)
