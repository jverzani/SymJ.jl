    Differential equations#

    SymJ.dsolve — Tuple{Relation, Sym, Vararg{Pair}}

    source 
    SymJ.dsolve(eq, y(x), ics...)

    Solve the ordinary differential equation eq (an equation, written with ~) for the function y(x). Derivatives are written diff(y(x), x) or y'(x). The result is an equation: y(x) ~ S with constants C1, C2, … (one for each order), or an implicit solution φ(x, y(x)) ~ C1 when y cannot be solved for.

    Initial conditions are pairs, one for each order: y(0) => 1, y'(0) => 0. They fix the constants.

    With series = n, the solution is a series about x0 (the point of the initial conditions, else 0) with error O((x - x0)^n), returned as the truncated sum. At an ordinary point it is the Taylor series, for any equation that can be solved for its highest derivative, nonlinear ones included; a linear one is grouped by constant, C1*(…) + C2*(…). At a regular singular point of a second-order linear homogeneous equation it is the Frobenius series, with a log term when the indicial roots are equal or an integer apart.

    Methods: first order linear, separable, Bernoulli, exact (with an integrating factor in x or y alone), homogeneous, Riccati; linear with constant coefficients, of any order (undetermined coefficients, else variation of parameters, for the right side); Cauchy–Euler; equations without y (reduced to a lower order); second order without x (autonomous: p = y' as a function of y). Integrals are done by the RischIntegrate extension when it is loaded (an unevaluated Integral otherwise, or when there is no elementary antiderivative).

    Not exported.

    @syms x y()
SymJ.dsolve(y'(x) ~ y(x), y(x))                          # y(x) ~ C1*exp(x)
SymJ.dsolve(y''(x) + y(x) ~ 0, y(x), y(0) => 0, y'(0) => 1)   # y(x) ~ sin(x)
SymJ.dsolve(y'(x) ~ x * y(x)^2, y(x))                    # y(x) ~ -2/(x^2 + 2C1)
SymJ.dsolve(x^2 * y''(x) - 2y(x) ~ 0, y(x))              # y(x) ~ C1/x + C2*x^2
SymJ.dsolve(y''(x) - x * y(x) ~ 0, y(x); series = 6)      # C1*(1 + x^3/6) + C2*(x + x^4/12)
    SymJ.dsolve([eq₁, eq₂, …], [y₁(t), y₂(t), …], ics...)

    A system of linear equations with constant coefficients, of any order, in normal form (the highest derivatives can be solved for). The result is a vector of equations, with as many constants as the unknowns' orders add up to; the initial conditions fix them, one for each unknown and each order below its highest. A right side F(t) is integrated in closed form when it is made of polynomials, exponentials, sines and cosines.

    @syms t u() v()
SymJ.dsolve([u'(t) ~ v(t), v'(t) ~ -u(t)], [u(t), v(t)])
# [u(t) ~ C1*sin(t) + C2*cos(t), v(t) ~ C1*cos(t) - C2*sin(t)]
SymJ.dsolve([u'(t) ~ v(t), v'(t) ~ -u(t)], [u(t), v(t)], u(0) => 1, v(0) => 0)
# [u(t) ~ cos(t), v(t) ~ -sin(t)]
