    Pattern matching#

    SymJ.pattern

    source 
    SymJ.pattern(ex)

    A pattern from the expression ex, usually quoted, in which ~x marks a slot:

    Slot In a function's arguments In a sum or product
    ~x one argument one or more terms (factors), bound to their sum (product)
    ~!x one argument any number; none gives 0 (1)
    ~~x any number, bound to a vector any number; none gives 0 (1)
    ~~~x one or more, bound to a vector one or more

    In an exponent, ~!n is 1 when there is no power. A head slot (~f)(~x) matches any function application and binds the function. ~x::pred (with any flavor) accepts only values for which pred returns true; a predicate's name is looked up in Main, then Base, then SymJ, or a function can be interpolated (:(~x::$f)).

    The pattern is put in canonical form, as any expression is (~x + ~x is 2*~x, exp(log(~x)) is ~x), and means what that form means. A number divides into a slot: ~x - ~y matches a - 2b with y => 2b.

    p = SymJ.pattern(:(~!a * sin(~x) + ~~r))
match(p, 3sin(t) + 1)          # Dict(:a => 3, :x => t, :r => 1)
eachmatch(SymJ.pattern(:(~x + ~y)), a + b + c)   # six matches
occursin(SymJ.pattern(:(sin(~x)^2)), 1 + sin(t)^2)   # true

    Not exported.

    SymJ.@pattern

    source 
    SymJ.@pattern ex

    The pattern SymJ.pattern makes from ex, written without quoting. The slots' predicates are evaluated where the macro is called, and $v puts in the value of v; other names are symbols (a in a pattern is Sym(:a)). Not exported.

    isodd3(n) = isodd(n) && n > 3
p = SymJ.@pattern (~x)^(~n::isodd3)
c = sin(t)
q = SymJ.@pattern ~x + $c

    SymJ.rule

    source 
    SymJ.rule(lhs => rhs)

    A rewrite rule made at run time: lhs is a pattern or a quoted pattern, and rhs either a quoted template, filled in with the bindings (~x its value, (~f)(…) the bound function, a sequence slot's arguments in place), or a function of the bindings (a Dict) that gives the value, or nothing to reject the match. See SymJ.@rule. Not exported.

    SymJ.rule(:(sin(~x)^2) => :(1 - cos(~x)^2))
SymJ.rule(:((~x)^(~n)) => d -> d[:n] * d[:x]^(d[:n] - 1))

    SymJ.@rule

    source 
    SymJ.@rule lhs => rhs

    A rewrite rule: when the pattern lhs (as for SymJ.@pattern) matches, the result is rhs, Julia code run where the macro is called with ~x the value bound to the slot ~x. A right side that gives nothing rejects the match, and the search goes on to the next. Use with SymJ.rewrite or replace, or call the rule on an expression. Not exported.

    r = SymJ.@rule sin(~x)^2 + cos(~x)^2 + ~~r => 1 + ~r
r(sin(t)^2 + cos(t)^2 + a)               # 1 + a
SymJ.@rule log(~x * ~y) => log(~x) + log(~y)
SymJ.@rule ~x^(~n::isinteger) => ~n * ~x^(~n - 1)
SymJ.@rule (~f)(~x + 2π) => (~f in (sin, cos) ? (~f)(~x) : nothing)

    SymJ.Pattern

    source 
    SymJ.Pattern

    A compiled pattern, made by SymJ.pattern and used with match, eachmatch and occursin.

    SymJ.Rule

    source 
    SymJ.Rule

    A rewrite rule, made by SymJ.@rule or SymJ.rule. Called on an expression, it gives the rewritten expression, or nothing when the left side doesn't match (or every match's right side is nothing).

    Base.eachmatch — Tuple{SymJ.Pattern, Any}

    source 
    eachmatch(p::SymJ.Pattern, ex)

    Every match of the pattern p against ex, as a vector of Dicts, in the order the search finds them. See SymJ.pattern.

    Base.match — Tuple{SymJ.Pattern, Any}

    source 
    match(p::SymJ.Pattern, ex)

    The first match of the pattern p against ex, as a Dict from slot names to values, or nothing. See SymJ.pattern.

    Base.occursin — Tuple{SymJ.Pattern, Any}

    source 
    occursin(p::SymJ.Pattern, ex)

    Whether the pattern p matches ex or a part of it: a term of a sum, a factor of a product, an argument. See SymJ.pattern.

    Base.replace — Tuple{Sym, SymJ.Rule}

    source 
    replace(ex::Sym, rules::SymJ.Rule...)
replace(ex::Sym, old => new, ...)
replace(f, ex::Sym)

    ex with its subexpressions replaced, in one pass from the leaves up (SymPy's replace): each part (a term of a sum, a factor of a product, a numeric coefficient, a power's base and exponent, a function's argument) is done first, then the expression made of the results is tried. At each subexpression the first replacement that applies is used, and a result is not searched again. old => new is one of:

    • a pattern (a SymJ.Pattern or a quoted one, :(sin(~x))) and a template or a function of the bindings, as for SymJ.rule;

    • a predicate and a function, (e -> SymJ.isnumber(e) && e > 2) => (e -> e - 1): each subexpression for which old(e) is true replaced by new(e);

    • an expression and a value: that subexpression (as subs does).

    replace(f, ex) (as Julia's replace(f, A)) replaces each subexpression e by f(e) (return e to keep it). With rules only, the one pass of SymJ.rewrite with fixpoint = false.

    @syms x y
replace(sin(x) + sin(y)^2, :(sin(~u)) => :(cos(~u)))              # cos(x) + cos(y)^2
replace(exp(x) + exp(2y), :(exp(~u)) => :(1 + ~u))                 # x + 2y + 2
replace(x^2 + 3x + 5, (e -> SymJ.isnumber(e) && e > 2) => (e -> e - 1))   # x^2 + 2x + 4
replace(e -> SymJ.isnumber(e) ? 2e : e, x^2 + 3x + 1)              # x^4 + 6x + 2

    SymJ.rewrite — Tuple{Any, Vararg{Any}}

    source 
    SymJ.rewrite(ex, rules...; order = :post, fixpoint = true, maxsteps = 100)

    ex with the rules applied wherever they match: to every part (the terms of a sum, the factors of a product, the arguments of a function), from the leaves up (order = :post) or from the top down (:pre). At each part the first rule that gives a result is used. With fixpoint = true the walk is repeated until nothing changes, at most maxsteps times, with a warning when that limit is reached. rules are SymJ.Rules, or vectors of them. Not exported.

    r = SymJ.@rule log(~x * ~y) => log(~x) + log(~y)
SymJ.rewrite(log(a * b * c), r)          # log(a) + log(b) + log(c)
