    Tutorial#

    This page works through the symbolic side of calculus with SymJ: making variables and expressions, evaluating and substituting, polynomials and rational functions, solving equations, and limits, derivatives and integrals. It follows the outline of the Giac page of Calculus with Julia.

    SymJ is one of several ways to do symbolic mathematics in Julia:

    • SymPy.jl connects to the Python library SymPy, a full-featured computer algebra system, which needs a Python installation.

    • Giac.jl wraps Giac, a mature computer algebra system written in C++.

    • Symbolics.jl is a numerically oriented system written in Julia, the basis of ModelingToolkit.

    • SymEngine.jl wraps SymEngine, a fast symbolic manipulation library written in C++.

    SymJ is written in Julia, aims to be fast, and keeps numbers exact. Limits are computed by GruntzLimit (a dependency) and integrals by RischIntegrate, two packages that work on the expressions of several symbolic systems, SymJ's among them.

    Julia versions

    SymJ and GruntzLimit support Julia 1.10 and later. RischIntegrate needs Julia 1.12 or later, so the section on integrals needs that version.

    using SymJ
using RischIntegrate

    A few ideas run through the package:

    • Variables are made with @syms, and generic Julia code (+, sin, ^, …) builds expressions from them.

    • Expressions are kept in a canonical form as they are built.

    • Numbers stay exact unless a floating point number is involved.

    • Expressions are callable: with numbers they evaluate, with pairs they substitute.

    Symbolic variables#

    The @syms macro makes variables and binds them to the same names:

    @syms x y
    \[\left( x, \; y \right)\]

    Sym(:z) makes one without binding a name, and symbols makes several from a string:

    z = Sym(:z)
a, b, c = symbols("a b c")
    \[\left( a, \; b, \; c \right)\]

    A symbolic function, with no rules of its own, is made with @syms f():

    @syms f()
f(x^2)
    \[f\left( x^{2} \right)\]

    Symbolic numbers#

    When a symbolic value meets a Julia integer or rational, the number becomes an exact symbolic number:

    2x, x / 3, (1 // 2) * x
    \[\left( 2 \cdot x, \; \frac{x}{3}, \; \frac{x}{2} \right)\]

    Sym makes an exact number directly. Exact numbers keep radicals and π exact, and simplify standard values:

    Sym(1 // 3), sqrt(Sym(8)), cos(Sym(π) / 6), Sym(2)^100
    \[\left( \frac{1}{3}, \; 2 \cdot \sqrt{2}, \; \frac{\sqrt{3}}{2}, \; 1267650600228229401496703205376 \right)\]

    Watch out for early conversion#

    Julia evaluates 1/2 before SymJ sees it, giving the float 0.5. A float in an expression makes the result a float, so x * (1/2) is not x/2:

    x / 2 == x * (1 // 2), x / 2 == x * (1 / 2)
    (true, false)

    The same holds for sqrt(2) or pi * 2 evaluated before meeting a symbol. Use 1//2, Sym(2), or let a symbolic value come first:

    sqrt(2) * x, sqrt(Sym(2)) * x, 2 * (pi * x)
    \[\left( 1.4142135623730951 \cdot x, \; \sqrt{2} \cdot x, \; 2 \cdot x \cdot \pi \right)\]

    Expressions#

    Expressions are built by applying functions to variables. They are kept in a canonical form: like terms are collected, numbers are combined, and products of powers merge.

    ex = x + 2x - y + x * y * x
    \[x^{2} \cdot y + 3 \cdot x - y\] 
    exp(x) * exp(2x), (x * y)^3, sin(-x)
    \[\left( e^{3 \cdot x}, \; x^{3} \cdot y^{3}, \; - \sin\left( x \right) \right)\]

    Functions with no numeric argument stay unevaluated, while exact values at standard points are simplified:

    sin(x), sin(Sym(π) / 4), log(Sym(1)), sin(2)
    (sin(x), sqrt(2)/2, 0, 0.9092974268256817)

    An expression is a tree: an operation applied to arguments. SymJ implements TermInterface, so operation and arguments take it apart:

    using SymJ: operation, arguments
F = 9 // 5 * (y - 32)
operation(F), arguments(F)
    (+, Sym[9*y/5, -288/5])

    Substitution#

    subs replaces symbols, or whole subexpressions, by other values:

    ex = a * x^2 + b * x + c
subs(ex, x => y - 1)
    \[a \cdot \left( y - 1 \right)^{2} + b \cdot \left( y - 1 \right) + c\] 
    subs(ex, a => 1, b => -2, c => 1)
    \[x^{2} - 2 \cdot x + 1\]

    Calling an expression with pairs does the same:

    ex(x => 2)
    \[4 \cdot a + 2 \cdot b + c\]

    Numerical evaluation#

    Calling an expression with a number evaluates it with Julia's arithmetic on that number, so the result is a Julia number of the matching type:

    u = x^2 - 2x + 1
u(3), u(3.0), u(1 // 3), u(big(2.5))
    (4, 4.0, 4//9, 2.25)

    Because the arithmetic is generic, automatic differentiation and other number types work through it. An expression can also be broadcast over a collection:

    u.(0:4)
    5-element Vector{Int64}:
 1
 0
 1
 4
 9

    With several variables, keywords give their values by name. When every variable has a numeric value the result is a Julia number, and otherwise the expression with the given values substituted:

    ex = a * x^2 + b * x + c
ex(; x = 2, a = 1, b = -3, c = 2), ex(; x = 2)
    (0, 4*a + 2*b + c)

    Names that don't appear are ignored, so one set of values can be used for several expressions:

    vals = (; x = 1.5, y = 2.0)
[e(; vals...) for e in (x + y, x * y, x^y)]
    3-element Vector{Float64}:
 3.5
 3.0
 2.25

    N gives the floating point value of a constant expression, and calling it with no arguments gives a Julia number:

    N(sqrt(Sym(2)) + Sym(π)), (Sym(3) // 4)()
    (4.555806215962888, 3//4)

    Calling interprets the expression each time. For many evaluations, lambdify compiles it into a Julia function, as fast as one written by hand:

    g = lambdify(sin(x)^2 + exp(-x / 2), x)
g(1.0)
    1.3146040779862047

    Plotting#

    Since an expression in one variable is callable, it can be passed where a function is expected, for instance to a plotting package:

    using Plots
plot(sin(x)^2 * exp(-x / 4), 0, 4pi)

    Polynomials#

    Construction#

    A polynomial expression can be expanded with expand:

    p = expand((x - 1) * (x - 2) * (x + 3))
    \[x^{3} - 7 \cdot x + 6\]

    Poly converts an expression into a polynomial in given generators. Its coefficients and exponents are available, and Sym converts it back:

    P = Poly(p, x)
coefficients(P), exponent_vectors(P), degree(P)
    (SymNumber[1, -7, 6], [[3], [1], [0]], 3)

    Other symbols become coefficients:

    Q = Poly(a * x^2 + b * x + c, x)
coefficients(Q)
    \[\left[ a, \; b, \; c \right]\]

    Evaluation and shifts#

    A polynomial is evaluated by calling it; a shift is a substitution:

    p(2), expand(p(x => x + 1))
    (0, x^3 + 3*x^2 - 4*x)

    Factoring#

    factor factors over the rationals, in any number of variables:

    factor(p), factor(x^4 + 4), factor(x^6 - y^6)
    \[\left( \left( x + 3 \right) \cdot \left( x - 1 \right) \cdot \left( x - 2 \right), \; \left( x^{2} + 2 \cdot x + 2 \right) \cdot \left( x^{2} - 2 \cdot x + 2 \right), \; \left( - x \cdot y + x^{2} + y^{2} \right) \cdot \left( x + y \right) \cdot \left( x - y \right) \cdot \left( x \cdot y + x^{2} + y^{2} \right) \right)\]

    factor_squarefree only separates repeated factors, which is cheaper:

    factor_squarefree(expand((x - 1)^3 * (x + 2)^2))
    \[\left( x + 2 \right)^{2} \cdot \left( x - 1 \right)^{3}\]

    The greatest common divisor of polynomials:

    gcd(expand((x - 1)^2 * (x + y)), expand((x - 1) * (x + y)^2))
    \[x \cdot y + x^{2} - x - y\]

    Resultants#

    The resultant of two polynomials in x is zero exactly when they have a common root. It is a polynomial in the other variables, so it eliminates x from a system:

    resultant(x^2 + y^2 - 1, x - y, x)
    \[2 \cdot y^{2} - 1\]

    The discriminant is zero exactly when a polynomial has a repeated root:

    @syms a b c
discriminant(a*x^2 + b*x + c, x), discriminant(x^3 + a*x + b, x)
    \[\left( -4 \cdot a \cdot c + b^{2}, \; -4 \cdot a^{3} - 27 \cdot b^{2} \right)\]

    Gröbner bases#

    A Gröbner basis of a set of polynomials generates the same ideal and has the same common zeros. In the lex order, the default, it is triangular: the last polynomials involve only the last variables.

    groebner([x^2 + y^2 - 1, x*y - 1//4], x, y)
    \[\left[ 4 \cdot y^{3} + x - 4 \cdot y, \; y^{4} - y^{2} + \frac{1}{16} \right]\]

    The basis is [1] exactly when the polynomials have no common zero:

    groebner([x^2 + y^2 - 1, x^2 + y^2 - 4], x, y)
    \[\left[ 1 \right]\]

    reduced divides by the basis. The remainder is zero exactly when a polynomial is in the ideal:

    G = groebner([x^2 + y^2 - 1, x - y], x, y)
reduced(x^2 - y^2, G, x, y), reduced(x^3, G, x, y)
    ((Sym[x + y, 0], 0), (Sym[x*y + x^2 + y^2, y], y/2))

    Roots#

    solve finds the roots of a polynomial. Degrees up to four are solved exactly, with real roots of cubics given in trigonometric form (no complex numbers needed):

    solve(p ~ 0, x)
    \[\left[ -3, \; 1, \; 2 \right]\] 
    solve(x^3 - 3x + 1 ~ 0, x)
    \[\left[ 2 \cdot \cos\left( \frac{10 \cdot \pi}{9} \right), \; 2 \cdot \cos\left( \frac{4 \cdot \pi}{9} \right), \; 2 \cdot \cos\left( \frac{2 \cdot \pi}{9} \right) \right]\] 
    solve(x^4 - 10x^2 + 1 ~ 0, x)
    \[\left[ - \sqrt{2 \cdot \sqrt{6} + 5}, \; - \sqrt{-2 \cdot \sqrt{6} + 5}, \; \sqrt{-2 \cdot \sqrt{6} + 5}, \; \sqrt{2 \cdot \sqrt{6} + 5} \right]\]

    From degree five, roots are computed numerically:

    solve(x^5 - x + 1 ~ 0, x)
    \[\left[ -1.1673039782614187, \; -1.0839541013177105 \cdot i - 0.18123244446987538, \; 1.0839541013177105 \cdot i - 0.18123244446987538, \; -0.35247154603172637 \cdot i + 0.7648844336005848, \; 0.3524715460317261 \cdot i + 0.7648844336005848 \right]\]

    Rational functions#

    cancel reduces a rational expression to lowest terms:

    r = (x^3 - 1) / (x^2 - 1)
cancel(r)
    \[\frac{x^{2} + x + 1}{x + 1}\] 
    cancel(1 / x + 1 / (x + 1))
    \[\frac{2 \cdot x + 1}{x^{2} + x}\]

    numer_denom gives the numerator and denominator without reducing:

    numer_denom(r)
    \[\left( x^{3} - 1, \; x^{2} - 1 \right)\]

    Partial fractions#

    apart decomposes a rational function into a polynomial part and simple fractions:

    apart((x^3 + 1) / (x^2 - 1), x)
    \[x + \frac{1}{x - 1}\] 
    apart(1 / (x^4 - 1), x)
    \[\frac{-1}{4 \cdot \left( x + 1 \right)} + \frac{1}{4 \cdot \left( x - 1 \right)} - \frac{1}{2 \cdot \left( x^{2} + 1 \right)}\]

    Other symbols are allowed in the coefficients:

    apart(1 / ((x - a) * (x - b)), x)
    \[\frac{-1}{\left( - a + b \right) \cdot \left( - a + x \right)} + \frac{1}{\left( - a + b \right) \cdot \left( - b + x \right)}\]

    Simplification#

    Expressions are kept in a canonical form as they are built, but that form does not cancel fractions, combine radicals or apply identities that need facts. simplify tries several transformations and keeps the smallest result:

    simplify((x^2 - 1) / (x - 1)), simplify((x + 1)^2 - x^2), simplify(sqrt(Sym(2)) * sqrt(Sym(3)))
    \[\left( x + 1, \; 2 \cdot x + 1, \; \sqrt{6} \right)\] 
    simplify(x / (x + 1) + 1 / (x + 1)), simplify(x^2 + 2x + 1)
    \[\left( 1, \; \left( x + 1 \right)^{2} \right)\]

    Identities such as sqrt(x^2) = x hold only for some values. Symbols are complex unless a fact says otherwise, so these need assumptions:

    simplify(sqrt(x^2)), simplify(sqrt(x^2); assume = @assume(x > 0)), simplify(sqrt(x^2); assume = @assume(x in Reals))
    \[\left( \sqrt{x^{2}}, \; x, \; \left|x\right| \right)\]

    Trigonometric identities are recognised, including multiple angles and sums of angles:

    simplify(1 - cos(x)^2), simplify(2sin(x) * cos(x)), simplify(sin(x) * cos(y) + cos(x) * sin(y))
    \[\left( \sin^{2}\left( x \right), \; \sin\left( 2 \cdot x \right), \; \sin\left( x + y \right) \right)\] 
    simplify(sin(3x) - 3sin(x) + 4sin(x)^3), simplify(1 / (1 + tan(x)^2))
    \[\left( 0, \; \cos^{2}\left( x \right) \right)\]

    Hyperbolic functions are treated the same way, and exponentials combine with both:

    simplify(cosh(x)^2 - sinh(x)^2), simplify(exp(x) + exp(-x)), simplify(cos(x) + im * sin(x))
    \[\left( 1, \; 2 \cdot \cosh\left( x \right), \; e^{i \cdot x} \right)\] 
    simplify(1 - tanh(x)^2), simplify(1 + tan(x)^2), simplify(cosh(x) / sinh(x))
    \[\left( \mathrm{sech}^{2}\left( x \right), \; \sec^{2}\left( x \right), \; \coth\left( x \right) \right)\]

    Logarithms combine and radicals denest; with symbols, where the assumptions allow:

    simplify(log(Sym(2)) + log(Sym(3))), simplify(sqrt(3 + 2sqrt(Sym(2)))), simplify(1 / (1 + sqrt(Sym(2))))
    \[\left( \log\left( 6 \right), \; \sqrt{2} + 1, \; \sqrt{2} - 1 \right)\] 
    simplify(log(x) + log(y); assume = @assume(x > 0, y > 0)), simplify(sqrt(x^2 + 2x + 1); assume = @assume(x > -1))
    \[\left( \log\left( x \cdot y \right), \; x + 1 \right)\]

    real, imag, conj and angle evaluate constants exactly; for symbols, which are complex, they take apart what holds for every value, and refine does the rest under assumptions:

    real(Sym(2) + 3im), conj(x + im), refine(real(exp(im * x)); assume = @assume(x in Reals))
    \[\left( 2, \; \mathrm{conj}\left( x \right) - i, \; \cos\left( x \right) \right)\]

    refine applies only those identities, without trying anything else:

    @syms n
refine(log(exp(x)); assume = @assume(x in Reals)), refine(sin(x + 2n*Sym(π)); assume = @assume(n in Integers))
    \[\left( x, \; \sin\left( x \right) \right)\]

    The transformations simplify tries are also available on their own, unexported: SymJ.simplify_rational, SymJ.simplify_powers, SymJ.simplify_trig, SymJ.simplify_hyperbolic, SymJ.simplify_log, SymJ.simplify_radicals and SymJ.simplify_gamma. The last combines factorials, binomials and gamma functions whose arguments differ by integers, and writes factorial ratios as binomials:

    @syms k
SymJ.simplify_gamma(factorial(n + 2) / factorial(n)), SymJ.simplify_gamma(binomial(n + 1, k) / binomial(n, k)), SymJ.simplify_gamma(factorial(n) / (factorial(k) * factorial(n - k)))
    \[\left( \left( n + 1 \right) \cdot \left( n + 2 \right), \; \frac{n + 1}{ - k + n + 1}, \; \binom{n}{k} \right)\]

    With the SpecialFunctions extension loaded it also applies the reflection formula (gamma(x)gamma(1 - x) = π/sin(πx)) and the duplication formula.

    Expansion goes the other way. SymJ.expand_trig writes trigonometric and hyperbolic functions of sums and integer multiples through functions of the terms:

    SymJ.expand_trig(sin(x + y)), SymJ.expand_trig(cos(3x)), SymJ.expand_trig(tan(2x))
    \[\left( \cos\left( x \right) \cdot \sin\left( y \right) + \cos\left( y \right) \cdot \sin\left( x \right), \; -3 \cdot \cos\left( x \right) + 4 \cdot \cos^{3}\left( x \right), \; \frac{-2 \cdot \tan\left( x \right)}{\tan^{2}\left( x \right) - 1} \right)\]

    SymJ.expand_log splits logarithms of products and powers where the assumptions allow it; force = true takes every base as positive:

    SymJ.expand_log(log(x^2 * y); assume = @assume(x > 0, y > 0)), SymJ.expand_log(log(x * y)), SymJ.expand_log(log(x / y); force = true)
    \[\left( 2 \cdot \log\left( x \right) + \log\left( y \right), \; \log\left( x \cdot y \right), \; \log\left( x \right) - \log\left( y \right) \right)\]

    Solving equations#

    An equation is written with ~, which binds more loosely than everything else, so no parentheses are needed:

    solve(x^2 + 2x ~ 3, x)
    \[\left[ -3, \; 1 \right]\]

    Equations in which x appears through one function are solved by solving for that function first:

    solve(exp(2x) - 3exp(x) + 2 ~ 0, x)
    \[\left[ 0, \; \log\left( 2 \right) \right]\] 
    solve(sqrt(x + 1) ~ x - 1, x)
    \[\left[ 3 \right]\]

    Several logarithms of the unknown are combined; roots where a logarithm would be complex (here x = -2) are dropped:

    solve(log(x) + log(x - 1) ~ log(Sym(6)), x)
    \[\left[ 3 \right]\]

    Some equations need the Lambert W function:

    solve(x * exp(x) ~ 1, x)
    \[\left[ \mathrm{lambertw}\left( 1 \right) \right]\]

    Symbols other than the unknown are allowed:

    solve(a * x^2 + b * x + c ~ 0, x)
    \[\left[ \frac{ - b - \sqrt{-4 \cdot a \cdot c + b^{2}}}{2 \cdot a}, \; \frac{ - b + \sqrt{-4 \cdot a \cdot c + b^{2}}}{2 \cdot a} \right]\]

    Inequalities#

    < and its relatives compare numbers and return true or false, so inequalities use other operators: ≪ (typed \ll), ≦ (\leqq), ≫ (\gg), ≧ (\geqq) and ≶ (\lessgtr). The solution is a union of intervals:

    solve(x^2 - 1 ≫ 0, x)
    \[\left( -\infty, -1 \right) \cup \left( 1, \infty \right)\] 
    solve((x - 1) / (x + 2) ≧ 0, x)
    \[\left( -\infty, -2 \right) \cup \left[ 1, \infty \right)\]

    Systems#

    A system of equations gives a vector of solutions, each a Dict from the unknowns to their values. A linear system has at most one:

    solve([x + y ~ 3, x - y ~ 1], [x, y])
    \[\left[ \begin{array}{l} \left\{ x = 2, \; y = 1 \right\} \end{array} \right]\] 
    solve([a * x + y ~ 1, x - y ~ b], [x, y])
    \[\left[ \begin{array}{l} \left\{ x = \frac{b + 1}{a + 1}, \; y = \frac{ - a \cdot b + 1}{a + 1} \right\} \end{array} \right]\]

    Polynomial systems are solved through a lex Gröbner basis, which is triangular:

    solve([x^2 + y^2 ~ 1, x ~ y], [x, y])
    \[\left[ \begin{array}{l} \left\{ x = \frac{ - \sqrt{2}}{2}, \; y = \frac{ - \sqrt{2}}{2} \right\} \\ \left\{ x = \frac{\sqrt{2}}{2}, \; y = \frac{\sqrt{2}}{2} \right\} \end{array} \right]\] 
    solve([x*y ~ 1, x + y ~ 3], [x, y])
    \[\left[ \begin{array}{l} \left\{ x = \frac{\sqrt{5}}{2} + \frac{3}{2}, \; y = \frac{ - \sqrt{5}}{2} + \frac{3}{2} \right\} \\ \left\{ x = \frac{ - \sqrt{5}}{2} + \frac{3}{2}, \; y = \frac{\sqrt{5}}{2} + \frac{3}{2} \right\} \end{array} \right]\]

    With infinitely many solutions, the unknowns left free map to themselves:

    solve([x^2 + y^2 ~ 1], [x, y])
    \[\left[ \begin{array}{l} \left\{ x = - \sqrt{ - y^{2} + 1}, \; y = y \right\} \\ \left\{ x = \sqrt{ - y^{2} + 1}, \; y = y \right\} \end{array} \right]\]

    A system of linear inequalities gives a description of the region, each unknown between bounds in the ones after it:

    solve([x ≧ 0, y ≧ 0, x + y ≦ 1], [x, y])
    \[y \in \left[ 0, 1 \right], \; x \in \left[ 0, - y + 1 \right]\]

    Assumptions#

    Symbols are complex numbers unless a fact says otherwise. Facts are relations, such as x > 0, or membership in one of Integers ⊂ Rationals ⊂ Reals ⊂ Complexes (also written ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ), such as n in Integers. The @assume macro writes them with Julia's operators, including &&, ||, ! and chained comparisons. They are given to solve with the assume keyword, and only the solutions they allow are kept:

    solve(x^2 ~ 4, x; assume = @assume(x > 0))
    \[\left[ 2 \right]\] 
    solve(x^2 + 1 ~ 0, x; assume = @assume(x in Reals))
    \[\left[ \; \right]\]

    Without the macro, relations use the symbolic operators: x ≫ 0 (or Gt(x, 0)), and n ∈ ℤ for membership.

    solve(x^2 ~ 2, x; assume = (x ∈ ℚ,))
    \[\left[ \; \right]\]

    @assuming gives facts for a block of code (as does the function assuming, with a do block):

    @assuming x > 0 begin
    solve(x^3 ~ 8, x), solve(x^2 - 5x + 6 ~ 0, x; assume = @assume(x > 2))
end
    \[\left( \left[ 2 \right], \; \left[ 3 \right] \right)\]

    When the answer depends on something the facts leave open, the result lists the cases:

    solve(x^2 ~ a, x; assume = @assume(x in Reals, a in Reals))
    \[\begin{cases} \left[ \; \right] & a < 0 \\ \left[ 0 \right] & a = 0 \\ \left[ - \sqrt{a}, \; \sqrt{a} \right] & a > 0 \end{cases}\]

    Without a ∈ ℝ, a may be complex, so the cases are a fact and its negation:

    cs = solve(x^2 ~ a, x; assume = @assume(x > 0))
    \[\begin{cases} \left[ \sqrt{a} \right] & a > 0 \\ \left[ \; \right] & \lnot \left( a > 0 \right) \end{cases}\]

    Calling the cases with a value gives the answer for it:

    cs(a => 4), cs(a => -1)
    \[\left( \left[ 2 \right], \; \left[ \; \right] \right)\]

    Contradictory facts are an error (@assume(x > 1 && x < 0)), and the Assumptions value @assume makes can be reused: A = @assume(x > 0, n in Integers), then assume = A.

    Sums#

    SymJ.summation(f, k, a, b) (not exported) sums f over k = a, …, b, in closed form where it finds one; b may be Inf:

    @syms k n r
SymJ.summation(k^2, k, 1, n), SymJ.summation(r^k, k, 0, n), SymJ.summation(1 / (k * (k + 1)), k, 1, n)
    \[\left( \frac{\left( 2 \cdot n + 1 \right) \cdot n \cdot \left( n + 1 \right)}{6}, \; \frac{r^{n + 1} - 1}{r - 1}, \; \frac{n}{n + 1} \right)\] 
    SymJ.summation(1 / k^2, k, 1, Inf), SymJ.summation(x^k / factorial(k), k, 0, Inf)
    \[\left( \frac{\pi^{2}}{6}, \; e^{x} \right)\]

    Definite sums of binomials, which have no antidifference, come from Zeilberger's algorithm:

    @syms m
SymJ.summation(binomial(n, k)^2, k, 0, n), SymJ.summation(binomial(n, k) * binomial(m, n - k), k, 0, n)
    \[\left( \binom{2 \cdot n}{n}, \; \binom{m + n}{m} \right)\]

    When Zeilberger's recurrence is of higher order, its hypergeometric solutions (found by Petkovšek's algorithm Hyper) may still give the sum; here Binet's formula for the Fibonacci numbers:

    SymJ.summation(binomial(n - k, k), k, 0, n)
    \[\left( \frac{ - \sqrt{5}}{10} + \frac{1}{2} \right) \cdot \left( \frac{ - \sqrt{5}}{2} + \frac{1}{2} \right)^{n} + \left( \frac{\sqrt{5}}{10} + \frac{1}{2} \right) \cdot \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n}\]

    The same algorithm solves linear recurrences, SymJ.rsolve (not exported), from initial values or in terms of them:

    @syms w()
SymJ.rsolve(w(n + 2) ~ w(n + 1) + w(n), w(n), w(0) => 0, w(1) => 1), SymJ.rsolve(w(n + 1) ~ 2w(n) + 1, w(n))
    \[\left( \frac{\sqrt{5} \cdot \left( - \left( \frac{ - \sqrt{5}}{2} + \frac{1}{2} \right)^{n} + \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n} \right)}{5}, \; 2^{n} \cdot \left( w\left( 0 \right) + 1 \right) - 1 \right)\]

    Whether a series converges can depend on a parameter; the answer then has cases, which assumptions settle:

    SymJ.summation(r^k, k, 0, Inf)
    \[\begin{cases} \text{the series diverges} & r \leq -1 \\ \frac{1}{ - r + 1} & -1 < r < 1 \\ \text{the series diverges} & r \geq 1 \end{cases}\] 
    SymJ.summation(k * r^k, k, 0, Inf; assume = @assume(0 < r < 1))
    \[\frac{r}{\left( r - 1 \right)^{2}}\]

    Matrices#

    Matrices of expressions are Julia arrays of Sym. With LinearAlgebra, det, inv, lu and \ work exactly, pivoting on the first nonzero entry rather than comparing magnitudes:

    using LinearAlgebra
@syms d
A = [a b; c d]
det(A), inv(A)
    \[\left( a \cdot d - b \cdot c, \; \left[ \begin{array}{cc} \frac{d}{a \cdot d - b \cdot c} & \frac{ - b}{a \cdot d - b \cdot c} \\ \frac{ - c}{a \cdot d - b \cdot c} & \frac{a}{a \cdot d - b \cdot c} \\ \end{array} \right] \right)\] 
    F = lu(A)
F.L, F.U
    \[\left( \left[ \begin{array}{cc} 1 & 0 \\ \frac{c}{a} & 1 \\ \end{array} \right], \; \left[ \begin{array}{cc} a & b \\ 0 & \frac{a \cdot d - b \cdot c}{a} \\ \end{array} \right] \right)\] 
    A \ [x, y]
    \[\left[ \frac{ - b \cdot y + d \cdot x}{a \cdot d - b \cdot c}, \; \frac{a \cdot y - c \cdot x}{a \cdot d - b \cdot c} \right]\]

    Row reduction (SymJ.rref, not exported, as it is not a LinearAlgebra function), rank, null spaces, and eigenvalues (with multiplicity) and eigenvectors:

    SymJ.rref(Sym[1 2 3; 4 5 6; 7 8 9]), nullspace(Sym[1 2 3; 4 5 6; 7 8 9])
    \[\left( \left[ \begin{array}{ccc} 1 & 0 & -1 \\ 0 & 1 & 2 \\ 0 & 0 & 0 \\ \end{array} \right], \; \left[ \begin{array}{c} 1 \\ -2 \\ 1 \\ \end{array} \right] \right)\] 
    eigvals(Sym[1 2; 3 4]), eigvecs([a b; b a])
    \[\left( \left[ \frac{ - \sqrt{33}}{2} + \frac{5}{2}, \; \frac{\sqrt{33}}{2} + \frac{5}{2} \right], \; \left[ \begin{array}{cc} 1 & -1 \\ 1 & 1 \\ \end{array} \right] \right)\]

    QR factorization by exact Gram–Schmidt, and functions of matrices through the Jordan form (SymJ.jordan_form), such as the exponential that solves x' = A x:

    Q, R = qr(Sym[3 1; 4 2])
Q, R
    \[\left( \left[ \begin{array}{cc} \frac{3}{5} & \frac{-4}{5} \\ \frac{4}{5} & \frac{3}{5} \\ \end{array} \right], \; \left[ \begin{array}{cc} 5 & \frac{11}{5} \\ 0 & \frac{2}{5} \\ \end{array} \right] \right)\] 
    @syms t n
exp(t * Sym[0 1; -1 0]), exp(t * Sym[2 1; 0 2])
    \[\left( \left[ \begin{array}{cc} \cos\left( t \right) & \sin\left( t \right) \\ - \sin\left( t \right) & \cos\left( t \right) \\ \end{array} \right], \; \left[ \begin{array}{cc} e^{2 \cdot t} & t \cdot e^{2 \cdot t} \\ 0 & e^{2 \cdot t} \\ \end{array} \right] \right)\] 
    Sym[1 1; 1 0]^n
    \[\left[ \begin{array}{cc} \frac{\sqrt{5} \cdot \left( - \left( \frac{ - \sqrt{5}}{2} + \frac{1}{2} \right)^{n + 1} + \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n + 1} \right)}{5} & \left( \frac{ - \sqrt{5}}{10} + \frac{1}{2} \right) \cdot \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n + 1} + \left( \frac{ - \sqrt{5}}{2} + \frac{1}{2} \right)^{n + 1} \cdot \left( \frac{\sqrt{5}}{10} + \frac{1}{2} \right) \\ \frac{\sqrt{5} \cdot \left( - \left( \frac{ - \sqrt{5}}{2} + \frac{1}{2} \right)^{n} + \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n} \right)}{5} & \left( \frac{ - \sqrt{5}}{10} + \frac{1}{2} \right) \cdot \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n} + \left( \frac{ - \sqrt{5}}{2} + \frac{1}{2} \right)^{n} \cdot \left( \frac{\sqrt{5}}{10} + \frac{1}{2} \right) \\ \end{array} \right]\]

    A - I works as for numbers; a symbolic multiple of the identity is λ*I(n):

    @syms λ
det([x 1; 1 x] - λ * I(2))
    \[-2 \cdot x \cdot \lambda + x^{2} + \lambda^{2} - 1\]

    Piecewise functions#

    SymJ.piecewise(c₁ => v₁, c₂ => v₂, …) (not exported) is the value of the first piece whose condition holds; a condition is a relation, a tuple of relations that all hold, or true. It is an expression like any other: substitution picks a piece, and diff, limit, refine and lambdify take it piece by piece:

    pw = SymJ.piecewise(x ≪ 0 => -x, (0 ≦ x, x ≪ 1) => x^2, true => 1)
pw, pw(x => -2), diff(pw, x)
    \[\left( \begin{cases} - x & \text{if } x < 0\\ x^{2} & \text{if } 0 \leq x < 1\\ 1 & \text{otherwise} \end{cases}, \; 2, \; \begin{cases} -1 & \text{if } x < 0\\ 2 \cdot x & \text{if } 0 \leq x < 1\\ 0 & \text{otherwise} \end{cases} \right)\] 
    limit(pw, x => 0), limit(pw, x => 1; dir = :-)
    \[\left( 0, \; 1 \right)\]

    The unit step SymJ.heaviside (½ at 0) and the delta SymJ.dirac are its derivative pair; SymJ.piecewise(ex) writes heaviside, sign, abs, max and min as pieces:

    H = SymJ.heaviside
diff(H(x - 1), x), SymJ.piecewise(abs(x - 1))
    \[\left( \delta\left( x - 1 \right), \; \begin{cases} x - 1 & \text{if } x > 1\\ - x + 1 & \text{otherwise} \end{cases} \right)\]

    Limits#

    limit(f, x => x0) is the limit of f as x tends to x0, a number, an expression or Inf. It is computed by Gruntz's algorithm, through GruntzLimit. An infinite limit is Sym(Inf) or Sym(-Inf):

    limit(sin(x) / x, x => 0)
    \[1\] 
    limit((1 + 1 / x)^x, x => Inf), limit(x * ((1 + 1 / x)^x - ℯ), x => Inf)
    \[\left( e, \; \frac{ - e}{2} \right)\] 
    limit((sin(x) - sin(Sym(π) / 6)) / (x - Sym(π) / 6), x => Sym(π) / 6)
    \[\frac{\sqrt{3}}{2}\]

    The limit is two-sided unless dir = :+ or dir = :- asks for a one-sided one:

    limit(x * exp(1 / x), x => 0; dir = :-), limit(x^x, x => 0; dir = :+)
    \[\left( 0, \; 1 \right)\]

    The algorithm handles cancellations that numerical evaluation cannot follow:

    limit(exp(x) * (exp(1 / x - exp(-x)) - exp(1 / x)), x => Inf)
    \[-1\]

    Other symbols may appear:

    limit((1 + a / x)^(b * x), x => Inf)
    \[e^{a \cdot b}\]

    The other symbols are taken to be real numbers. When the limit depends on their values, limit gives it for each case:

    limit(x^a, x => Inf)
    \[\begin{cases} 0 & a < 0 \\ 1 & a = 0 \\ \infty & a > 0 \end{cases}\]

    Assumptions, as in the section on solving, settle cases:

    limit(x^a, x => Inf; assume = @assume(a > 1)), limit((a^x + b^x)^(1 / x), x => Inf; assume = @assume(a > b > 0))
    \[\left( \infty, \; a \right)\]

    Derivatives#

    diff(f, x) differentiates with respect to x, and diff(f, x, n) gives the n-th derivative:

    diff(sin(x)^2 * exp(x), x)
    \[2 \cdot \cos\left( x \right) \cdot \sin\left( x \right) \cdot e^{x} + \sin^{2}\left( x \right) \cdot e^{x}\] 
    diff(x^x, x), diff(atan(x), x, 3)
    \[\left( \left( \log\left( x \right) + 1 \right) \cdot x^{x}, \; \frac{-2}{\left( x^{2} + 1 \right)^{2}} + \frac{8 \cdot x^{2}}{\left( x^{2} + 1 \right)^{3}} \right)\]

    Mixed partial derivatives take the variables in order: diff(f, x, y) differentiates with respect to x, then y:

    diff(x^3 * y^2, x, y), diff(sin(x * y), x, y), diff(x^2 * y * z, x, x, y, z)
    \[\left( 6 \cdot x^{2} \cdot y, \; - \sin\left( x \cdot y \right) \cdot x \cdot y + \cos\left( x \cdot y \right), \; 2 \right)\]

    A symbolic function gives an unevaluated derivative:

    diff(f(x^2), x)
    \[\mathrm{Derivative}\left( f\left( x^{2} \right), x \right)\]

    Critical points#

    The critical points of a function are the zeros of its derivative, and the second derivative classifies them:

    h = x^3 - 6x^2 + 9x + 1
cps = solve(diff(h, x) ~ 0, x)
    \[\left[ 1, \; 3 \right]\] 
    h2 = diff(h, x, 2)
[(c, h(c), h2(c)) for c in cps]
    2-element Vector{Tuple{Sym, Sym, Sym}}:
 (1, 5, -6)
 (3, 1, 6)

    So 1 is a local maximum and 3 a local minimum.

    Tangent lines#

    The tangent line at c is h(c) + h'(c)(x - c):

    c₀ = 2
expand(h(c₀) + diff(h, x)(c₀) * (x - c₀))
    \[-3 \cdot x + 9\]

    Series#

    series(ex, x, x0, n) expands ex about x0 with an error of order (x - x0)^n; x0 defaults to 0 and n to 6:

    series(sin(x), x)
    \[x - \frac{x^{3}}{6} + \frac{x^{5}}{120} + O\left( x^{6} \right)\] 
    series(exp(x), x, 1, 3)
    \[e + e \cdot \left( x - 1 \right) + \frac{e}{2} \cdot \left( x - 1 \right)^{2} + O\left( \left( x - 1 \right)^{3} \right)\]

    Laurent series (negative powers), Puiseux series (fractional powers), logarithmic terms and expansions at infinity (in powers of 1/x) are included:

    series(cot(x), x, 0, 4), series(sqrt(x + x^2), x, 0, 3)
    \[\left( \frac{1}{x} - \frac{x}{3} - \frac{x^{3}}{45} + O\left( x^{4} \right), \; \sqrt{x} + \frac{x^{\frac{3}{2}}}{2} - \frac{x^{\frac{5}{2}}}{8} + O\left( x^{3} \right) \right)\] 
    series(x^x, x, 0, 3), series(sqrt(x^2 + x), x, Inf, 3)
    \[\left( 1 + \log\left( x \right) \cdot x + \frac{\left( \log\left( x \right) \right)^{2} \cdot x^{2}}{2} + O\left( x^{3} \right), \; x + \frac{1}{2} - \frac{1}{8 \cdot x} + \frac{1}{16 \cdot x^{2}} + O\left( \frac{1}{x^{3}} \right) \right)\]

    A series is an object that keeps its error term. Series about the same point can be added, multiplied and divided, with the order tracked, and Sym drops the O term:

    s, c = series(sin(x), x), series(cos(x), x)
s / c
    \[x + \frac{x^{3}}{3} + \frac{2 \cdot x^{5}}{15} + O\left( x^{6} \right)\] 
    Sym(s)
    \[\frac{x^{5}}{120} - \frac{x^{3}}{6} + x\]

    Integrals#

    Antiderivatives come from integrate, from RischIntegrate, an implementation of the Risch algorithm. It decides whether an elementary antiderivative exists, and finds it:

    integrate(x^2 * exp(x), x)
    \[\left( x^{2} - 2 \cdot x + 2 \right) \cdot e^{x}\] 
    integrate(1 / (x^3 + 1), x)
    \[\frac{\log\left( x + 1 \right)}{3} - \frac{\log\left( x^{2} - x + 1 \right)}{6} + \frac{\sqrt{3} \cdot \arctan\left( \sqrt{3} \cdot \left( \frac{2 \cdot x}{3} - \frac{1}{3} \right) \right)}{3}\] 
    integrate(1 / (x^3 - x), x), integrate((2x + 3) / (x^2 + 1), x)
    \[\left( - \log\left( x \right) + \frac{\log\left( x^{2} - 1 \right)}{2}, \; 3 \cdot \arctan\left( x \right) + \log\left( x^{2} + 1 \right) \right)\] 
    integrate(sin(x)^3, x), integrate(sqrt(1 - x^2), x)
    \[\left( \frac{\cos\left( 3 \cdot x \right)}{12} - \frac{3 \cdot \cos\left( x \right)}{4}, \; \frac{\sqrt{ - x^{2} + 1} \cdot x}{2} + \frac{\arcsin\left( x \right)}{2} \right)\] 
    integrate(x * log(x), x), integrate(1 / (x * log(x)), x)
    \[\left( \frac{\log\left( x \right) \cdot x^{2}}{2} - \frac{x^{2}}{4}, \; \log\left( \log\left( x \right) \right) \right)\]

    Piecewise functions, heaviside, abs and sign are integrated interval by interval, the antiderivative made continuous; a dirac picks out a value:

    integrate(x * H(x - 1), x), integrate(cos(x) * SymJ.dirac(x - 1), x)
    \[\left( \begin{cases} 0 & \text{if } x < 1\\ \frac{x^{2}}{2} - \frac{1}{2} & \text{otherwise} \end{cases}, \; \cos\left( 1 \right) \cdot \theta\left( x - 1 \right) \right)\]

    Definite integrals#

    A definite integral is the difference of an antiderivative's values at the end points. Calling the antiderivative with exact numbers keeps the answer exact:

    F = integrate(x^2, x)
F(3) - F(0)
    9//1
    integrate(abs(x - 1), (x, 0, 3))
    \[\frac{5}{2}\] 
    G = integrate(sin(x), x)
G(x => Sym(π)) - G(x => 0)
    \[2\]

    Differential equations#

    SymJ.dsolve solves an ordinary differential equation for an unknown function. The function is made with @syms y(), and its derivatives are written y'(x), y''(x) (or diff(y(x), x)). The answer is an equation, with constants C1, C2, …:

    @syms y()
SymJ.dsolve(y'(x) + 2y(x) ~ exp(x), y(x))
    \[y\left( x \right) = \frac{C1}{e^{2 \cdot x}} + \frac{e^{x}}{3}\]

    First-order equations that are linear, separable, Bernoulli, exact or homogeneous are recognized:

    SymJ.dsolve(y'(x) ~ x * y(x)^2, y(x)), SymJ.dsolve(y'(x) ~ (x + y(x)) / x, y(x))
    \[\left( y\left( x \right) = \frac{-2}{x^{2} + C1}, \; y\left( x \right) = \left( C1 + \log\left( x \right) \right) \cdot x \right)\]

    When y cannot be solved for, the solution is implicit:

    SymJ.dsolve(2x * y(x) + (x^2 + 3y(x)^2) * y'(x) ~ 0, y(x))
    \[x^{2} \cdot y\left( x \right) + \left( y\left( x \right) \right)^{3} = C1\]

    Linear equations with constant coefficients, of any order, are solved through the roots of the characteristic polynomial; a right side is handled by undetermined coefficients, or by variation of parameters:

    SymJ.dsolve(y''(x) + 2y'(x) + 5y(x) ~ 0, y(x)), SymJ.dsolve(y''(x) + y(x) ~ sin(x), y(x))
    \[\left( y\left( x \right) = \frac{C1 \cdot \cos\left( 2 \cdot x \right) + C2 \cdot \sin\left( 2 \cdot x \right)}{e^{x}}, \; y\left( x \right) = C1 \cdot \cos\left( x \right) + C2 \cdot \sin\left( x \right) - \frac{\cos\left( x \right) \cdot x}{2} \right)\] 
    SymJ.dsolve(y''(x) + y(x) ~ tan(x), y(x))
    \[y\left( x \right) = C1 \cdot \cos\left( x \right) + C2 \cdot \sin\left( x \right) + \frac{\cos\left( x \right) \cdot \log\left( -2 \cdot \sin\left( x \right) + 2 \right)}{2} - \frac{\cos\left( x \right) \cdot \log\left( 2 \cdot \sin\left( x \right) + 2 \right)}{2}\]

    Cauchy–Euler equations, with coefficients x^k on y⁽ᵏ⁾, are solved too:

    SymJ.dsolve(x^2 * y''(x) - 2y(x) ~ 0, y(x))
    \[y\left( x \right) = C2 \cdot x^{2} + \frac{C1}{x}\]

    Initial conditions, one for each order, fix the constants:

    SymJ.dsolve(y''(x) + y(x) ~ 0, y(x), y(0) => 0, y'(0) => 1)
    \[y\left( x \right) = \sin\left( x \right)\] 
    SymJ.dsolve(y'(x) ~ -x / y(x), y(x), y(0) => 2)
    \[y\left( x \right) = \sqrt{ - x^{2} + 4}\]
