    Tutorial#

    This page works through the symbolic side of calculus with SymJ: making variables and expressions, evaluating and substituting, polynomials and rational functions, solving equations, and limits, derivatives and integrals. It follows the outline of the Giac page of Calculus with Julia.

    SymJ is one of several ways to do symbolic mathematics in Julia:

    • SymPy.jl connects to the Python library SymPy, a full-featured computer algebra system, which needs a Python installation.

    • Giac.jl wraps Giac, a mature computer algebra system written in C++.

    • Symbolics.jl is a numerically oriented system written in Julia, the basis of ModelingToolkit.

    • SymEngine.jl wraps SymEngine, a fast symbolic manipulation library written in C++.

    SymJ is written in Julia, aims to be fast, and keeps numbers exact. Limits come from GruntzLimit and integrals from RischIntegrate, two packages that work on the expressions of several symbolic systems, SymJ's among them.

    Julia versions

    SymJ and GruntzLimit support Julia 1.10 and later. RischIntegrate needs Julia 1.12 or later, so the section on integrals needs that version.

    using SymJ
import GruntzLimit: limit
using RischIntegrate

    A few ideas run through the package:

    • Variables are made with @syms, and generic Julia code (+, sin, ^, …) builds expressions from them.

    • Expressions are kept in a canonical form as they are built.

    • Numbers stay exact unless a floating point number is involved.

    • Expressions are callable: with numbers they evaluate, with pairs they substitute.

    Symbolic variables#

    The @syms macro makes variables and binds them to the same names:

    @syms x y
    (x, y)

    Sym(:z) makes one without binding a name, and symbols makes several from a string:

    z = Sym(:z)
a, b, c = symbols("a b c")
    (a, b, c)

    A symbolic function, with no rules of its own, is made with @syms f():

    @syms f()
f(x^2)
    f(x^2)

    Symbolic numbers#

    When a symbolic value meets a Julia integer or rational, the number becomes an exact symbolic number:

    2x, x / 3, (1 // 2) * x
    (2*x, x/3, x/2)

    Sym makes an exact number directly. Exact numbers keep radicals and π exact, and simplify standard values:

    Sym(1 // 3), sqrt(Sym(8)), cos(Sym(π) / 6), Sym(2)^100
    (1/3, 2*sqrt(2), sqrt(3)/2, 1267650600228229401496703205376)

    Watch out for early conversion#

    Julia evaluates 1/2 before SymJ sees it, giving the float 0.5. A float in an expression makes the result a float, so x * (1/2) is not x/2:

    x / 2 == x * (1 // 2), x / 2 == x * (1 / 2)
    (true, false)

    The same holds for sqrt(2) or pi * 2 evaluated before meeting a symbol. Use 1//2, Sym(2), or let a symbolic value come first:

    sqrt(2) * x, sqrt(Sym(2)) * x, 2 * (pi * x)
    (1.4142135623730951*x, sqrt(2)*x, 2*x*π)

    Expressions#

    Expressions are built by applying functions to variables. They are kept in a canonical form: like terms are collected, numbers are combined, and products of powers merge.

    ex = x + 2x - y + x * y * x
    x^2*y + 3*x - y
    exp(x) * exp(2x), (x * y)^3, sin(-x)
    (exp(3*x), x^3*y^3, -sin(x))

    Functions with no numeric argument stay unevaluated, while exact values at standard points are simplified:

    sin(x), sin(Sym(π) / 4), log(Sym(1)), sin(2)
    (sin(x), sqrt(2)/2, 0, 0.9092974268256817)

    An expression is a tree: an operation applied to arguments. SymJ implements TermInterface, so operation and arguments take it apart:

    using SymJ: operation, arguments
F = 9 // 5 * (y - 32)
operation(F), arguments(F)
    (+, Sym[9*y/5, -288/5])

    Substitution#

    subs replaces symbols, or whole subexpressions, by other values:

    ex = a * x^2 + b * x + c
subs(ex, x => y - 1)
    a*(y - 1)^2 + b*(y - 1) + c
    subs(ex, a => 1, b => -2, c => 1)
    x^2 - 2*x + 1

    Calling an expression with pairs does the same:

    ex(x => 2)
    4*a + 2*b + c

    Numerical evaluation#

    Calling an expression with a number evaluates it with Julia's arithmetic on that number, so the result is a Julia number of the matching type:

    u = x^2 - 2x + 1
u(3), u(3.0), u(1 // 3), u(big(2.5))
    (4, 4.0, 4//9, 2.25)

    Because the arithmetic is generic, automatic differentiation and other number types work through it. An expression can also be broadcast over a collection:

    u.(0:4)
    5-element Vector{Int64}:
 1
 0
 1
 4
 9

    With several variables, keywords give their values by name. When every variable has a numeric value the result is a Julia number, and otherwise the expression with the given values substituted:

    ex = a * x^2 + b * x + c
ex(; x = 2, a = 1, b = -3, c = 2), ex(; x = 2)
    (0, 4*a + 2*b + c)

    Names that don't appear are ignored, so one set of values can be used for several expressions:

    vals = (; x = 1.5, y = 2.0)
[e(; vals...) for e in (x + y, x * y, x^y)]
    3-element Vector{Float64}:
 3.5
 3.0
 2.25

    N gives the floating point value of a constant expression, and calling it with no arguments gives a Julia number:

    N(sqrt(Sym(2)) + Sym(π)), (Sym(3) // 4)()
    (4.555806215962888, 3//4)

    Calling interprets the expression each time. For many evaluations, lambdify compiles it into a Julia function, as fast as one written by hand:

    g = lambdify(sin(x)^2 + exp(-x / 2), x)
g(1.0)
    1.3146040779862047

    Plotting#

    Since an expression in one variable is callable, it can be passed where a function is expected, for instance to a plotting package:

    using Plots
plot(sin(x)^2 * exp(-x / 4), 0, 4pi)

    Polynomials#

    Construction#

    A polynomial expression can be expanded with expand:

    p = expand((x - 1) * (x - 2) * (x + 3))
    x^3 - 7*x + 6

    Poly converts an expression into a polynomial in given generators. Its coefficients and exponents are available, and Sym converts it back:

    P = Poly(p, x)
coefficients(P), exponent_vectors(P), degree(P)
    (SymNumber[1, -7, 6], [[3], [1], [0]], 3)

    Other symbols become coefficients:

    Q = Poly(a * x^2 + b * x + c, x)
coefficients(Q)
    3-element Vector{Sym}:
 a
 b
 c

    Evaluation and shifts#

    A polynomial is evaluated by calling it; a shift is a substitution:

    p(2), expand(p(x => x + 1))
    (0, x^3 + 3*x^2 - 4*x)

    Factoring#

    factor factors over the rationals, in any number of variables:

    factor(p), factor(x^4 + 4), factor(x^6 - y^6)
    ((x + 3)*(x - 1)*(x - 2), (x^2 + 2*x + 2)*(x^2 - 2*x + 2), (-x*y + x^2 + y^2)*(x + y)*(x - y)*(x*y + x^2 + y^2))

    factor_squarefree only separates repeated factors, which is cheaper:

    factor_squarefree(expand((x - 1)^3 * (x + 2)^2))
    (x + 2)^2*(x - 1)^3

    The greatest common divisor of polynomials:

    gcd(expand((x - 1)^2 * (x + y)), expand((x - 1) * (x + y)^2))
    x*y + x^2 - x - y

    Resultants#

    The resultant of two polynomials in x is zero exactly when they have a common root. It is a polynomial in the other variables, so it eliminates x from a system:

    resultant(x^2 + y^2 - 1, x - y, x)
    2*y^2 - 1

    The discriminant is zero exactly when a polynomial has a repeated root:

    @syms a b c
discriminant(a*x^2 + b*x + c, x), discriminant(x^3 + a*x + b, x)
    (-4*a*c + b^2, -4*a^3 - 27*b^2)

    Gröbner bases#

    A Gröbner basis of a set of polynomials generates the same ideal and has the same common zeros. In the lex order, the default, it is triangular: the last polynomials involve only the last variables.

    groebner([x^2 + y^2 - 1, x*y - 1//4], x, y)
    2-element Vector{Sym}:
 4*y^3 + x - 4*y
 y^4 - y^2 + 1/16

    The basis is [1] exactly when the polynomials have no common zero:

    groebner([x^2 + y^2 - 1, x^2 + y^2 - 4], x, y)
    1-element Vector{Sym}:
 1

    reduced divides by the basis. The remainder is zero exactly when a polynomial is in the ideal:

    G = groebner([x^2 + y^2 - 1, x - y], x, y)
reduced(x^2 - y^2, G, x, y), reduced(x^3, G, x, y)
    ((Sym[x + y, 0], 0), (Sym[x*y + x^2 + y^2, y], y/2))

    Roots#

    solve finds the roots of a polynomial. Degrees up to four are solved exactly, with real roots of cubics given in trigonometric form (no complex numbers needed):

    solve(p ~ 0, x)
    3-element Vector{Sym}:
 -3
 1
 2
    solve(x^3 - 3x + 1 ~ 0, x)
    3-element Vector{Sym}:
 2*cos(10*π/9)
 2*cos(4*π/9)
 2*cos(2*π/9)
    solve(x^4 - 10x^2 + 1 ~ 0, x)
    4-element Vector{Sym}:
 -sqrt(2*sqrt(6) + 5)
 -sqrt(-2*sqrt(6) + 5)
 sqrt(-2*sqrt(6) + 5)
 sqrt(2*sqrt(6) + 5)

    From degree five, roots are computed numerically:

    solve(x^5 - x + 1 ~ 0, x)
    5-element Vector{Sym}:
 -1.1673039782614187
 -1.0839541013177105*im - 0.18123244446987538
 1.0839541013177105*im - 0.18123244446987538
 -0.35247154603172637*im + 0.7648844336005848
 0.3524715460317261*im + 0.7648844336005848

    Rational functions#

    cancel reduces a rational expression to lowest terms:

    r = (x^3 - 1) / (x^2 - 1)
cancel(r)
    (x^2 + x + 1)/(x + 1)
    cancel(1 / x + 1 / (x + 1))
    (2*x + 1)/(x^2 + x)

    numer_denom gives the numerator and denominator without reducing:

    numer_denom(r)
    (x^3 - 1, x^2 - 1)

    Partial fractions#

    apart decomposes a rational function into a polynomial part and simple fractions:

    apart((x^3 + 1) / (x^2 - 1), x)
    x + 1/(x - 1)
    apart(1 / (x^4 - 1), x)
    -1/(4*(x + 1)) + 1/(4*(x - 1)) - 1/(2*(x^2 + 1))

    Other symbols are allowed in the coefficients:

    apart(1 / ((x - a) * (x - b)), x)
    -1/((-a + b)*(-a + x)) + 1/((-a + b)*(-b + x))

    Solving equations#

    An equation is written with ~, which binds more loosely than everything else, so no parentheses are needed:

    solve(x^2 + 2x ~ 3, x)
    2-element Vector{Sym}:
 -3
 1

    Equations in which x appears through one function are solved by solving for that function first:

    solve(exp(2x) - 3exp(x) + 2 ~ 0, x)
    2-element Vector{Sym}:
 0
 log(2)
    solve(sqrt(x + 1) ~ x - 1, x)
    1-element Vector{Sym}:
 3

    Several logarithms of the unknown are combined; roots where a logarithm would be complex (here x = -2) are dropped:

    solve(log(x) + log(x - 1) ~ log(Sym(6)), x)
    1-element Vector{Sym}:
 3

    Some equations need the Lambert W function:

    solve(x * exp(x) ~ 1, x)
    1-element Vector{Sym}:
 lambertw(1)

    Symbols other than the unknown are allowed:

    solve(a * x^2 + b * x + c ~ 0, x)
    2-element Vector{Sym}:
 (-b - sqrt(-4*a*c + b^2))/(2*a)
 (-b + sqrt(-4*a*c + b^2))/(2*a)

    Inequalities#

    < and its relatives compare numbers and return true or false, so inequalities use other operators: ≪ (typed \ll), ≦ (\leqq), ≫ (\gg), ≧ (\geqq) and ≶ (\lessgtr). The solution is a union of intervals:

    solve(x^2 - 1 ≫ 0, x)
    (-∞, -1) ∪ (1, ∞)
    solve((x - 1) / (x + 2) ≧ 0, x)
    (-∞, -2) ∪ [1, ∞)

    Systems#

    A system of equations gives a vector of solutions, each a Dict from the unknowns to their values. A linear system has at most one:

    solve([x + y ~ 3, x - y ~ 1], [x, y])
    1-element Vector{Dict{Sym, Sym}}:
 Dict(y => 1, x => 2)
    solve([a * x + y ~ 1, x - y ~ b], [x, y])
    1-element Vector{Dict{Sym, Sym}}:
 Dict(y => (-a*b + 1)/(a + 1), x => (b + 1)/(a + 1))

    Polynomial systems are solved through a lex Gröbner basis, which is triangular:

    solve([x^2 + y^2 ~ 1, x ~ y], [x, y])
    2-element Vector{Dict{Sym, Sym}}:
 Dict(y => -sqrt(2)/2, x => -sqrt(2)/2)
 Dict(y => sqrt(2)/2, x => sqrt(2)/2)
    solve([x*y ~ 1, x + y ~ 3], [x, y])
    2-element Vector{Dict{Sym, Sym}}:
 Dict(y => -sqrt(5)/2 + 3/2, x => sqrt(5)/2 + 3/2)
 Dict(y => sqrt(5)/2 + 3/2, x => -sqrt(5)/2 + 3/2)

    With infinitely many solutions, the unknowns left free map to themselves:

    solve([x^2 + y^2 ~ 1], [x, y])
    2-element Vector{Dict{Sym, Sym}}:
 Dict(y => y, x => -sqrt(-y^2 + 1))
 Dict(y => y, x => sqrt(-y^2 + 1))

    A system of linear inequalities gives a description of the region, each unknown between bounds in the ones after it:

    solve([x ≧ 0, y ≧ 0, x + y ≦ 1], [x, y])
    y ∈ [0, 1], x ∈ [0, -y + 1]

    Assumptions#

    Symbols are complex numbers unless a fact says otherwise. Facts are relations, such as x > 0, or membership in one of Integers ⊂ Rationals ⊂ Reals ⊂ Complexes (also written ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ), such as n in Integers. The @assume macro writes them with Julia's operators, including &&, ||, ! and chained comparisons. They are given to solve with the assume keyword, and only the solutions they allow are kept:

    solve(x^2 ~ 4, x; assume = @assume(x > 0))
    1-element Vector{Sym}:
 2
    solve(x^2 + 1 ~ 0, x; assume = @assume(x in Reals))
    Sym[]

    Without the macro, relations use the symbolic operators: x ≫ 0 (or Gt(x, 0)), and n ∈ ℤ for membership.

    solve(x^2 ~ 2, x; assume = (x ∈ ℚ,))
    Sym[]

    @assuming gives facts for a block of code (as does the function assuming, with a do block):

    @assuming x > 0 begin
    solve(x^3 ~ 8, x), solve(x^2 - 5x + 6 ~ 0, x; assume = @assume(x > 2))
end
    (Sym[2], Sym[3])

    When the answer depends on something the facts leave open, the result lists the cases:

    solve(x^2 ~ a, x; assume = @assume(x in Reals, a in Reals))
    Cases with 3 cases:
  a < 0  =>  []
  a == 0  =>  [0]
  a > 0  =>  [-sqrt(a), sqrt(a)]

    Without a ∈ ℝ, a may be complex, so the cases are a fact and its negation:

    cs = solve(x^2 ~ a, x; assume = @assume(x > 0))
    Cases with 2 cases:
  a > 0  =>  [sqrt(a)]
  !(a > 0)  =>  []

    Calling the cases with a value gives the answer for it:

    cs(a => 4), cs(a => -1)
    (Sym[2], Sym[])

    Contradictory facts are an error (@assume(x > 1 && x < 0)), and the Assumptions value @assume makes can be reused: A = @assume(x > 0, n in Integers), then assume = A.

    Limits#

    Limits are computed by limit from GruntzLimit, which implements Gruntz's algorithm. limit(f, x => x0) is the limit of f as x tends to x0, a number, an expression or Inf:

    limit(sin(x) / x, x => 0)
    1
    limit((1 + 1 / x)^x, x => Inf), limit(x * ((1 + 1 / x)^x - ℯ), x => Inf)
    (ℯ, -ℯ/2)
    limit((sin(x) - sin(Sym(π) / 6)) / (x - Sym(π) / 6), x => Sym(π) / 6)
    sqrt(3)/2

    The limit is two-sided unless dir = :+ or dir = :- asks for a one-sided one:

    limit(x * exp(1 / x), x => 0; dir = :-), limit(x^x, x => 0; dir = :+)
    (0, 1)

    The algorithm handles cancellations that numerical evaluation cannot follow:

    limit(exp(x) * (exp(1 / x - exp(-x)) - exp(1 / x)), x => Inf)
    -1

    Other symbols may appear:

    limit((1 + a / x)^(b * x), x => Inf)
    exp(a*b)

    When the limit depends on the values of the other symbols, limit gives it for each case:

    limit(x^a, x => Inf)
    LimitCases with 3 cases:
  a < 0  =>  0
  a == 0  =>  1
  a > 0  =>  Inf

    Derivatives#

    diff(f, x) differentiates with respect to x, and diff(f, x, n) gives the n-th derivative:

    diff(sin(x)^2 * exp(x), x)
    2*cos(x)*sin(x)*exp(x) + sin(x)^2*exp(x)
    diff(x^x, x), diff(atan(x), x, 3)
    ((log(x) + 1)*x^x, -2/(x^2 + 1)^2 + 8*x^2/(x^2 + 1)^3)

    Mixed partial derivatives take the variables in order: diff(f, x, y) differentiates with respect to x, then y:

    diff(x^3 * y^2, x, y), diff(sin(x * y), x, y), diff(x^2 * y * z, x, x, y, z)
    (6*x^2*y, -sin(x*y)*x*y + cos(x*y), 2)

    A symbolic function gives an unevaluated derivative:

    diff(f(x^2), x)
    Derivative(f(x^2), x)

    Critical points#

    The critical points of a function are the zeros of its derivative, and the second derivative classifies them:

    h = x^3 - 6x^2 + 9x + 1
cps = solve(diff(h, x) ~ 0, x)
    2-element Vector{Sym}:
 1
 3
    h2 = diff(h, x, 2)
[(c, h(c), h2(c)) for c in cps]
    2-element Vector{Tuple{Sym, Sym, Sym}}:
 (1, 5, -6)
 (3, 1, 6)

    So 1 is a local maximum and 3 a local minimum.

    Tangent lines#

    The tangent line at c is h(c) + h'(c)(x - c):

    c₀ = 2
expand(h(c₀) + diff(h, x)(c₀) * (x - c₀))
    -3*x + 9

    Series#

    series(ex, x, x0, n) expands ex about x0 with an error of order (x - x0)^n; x0 defaults to 0 and n to 6:

    series(sin(x), x)
    x - x^3/6 + x^5/120 + O(x^6)
    series(exp(x), x, 1, 3)
    ℯ + ℯ*(x - 1) + ℯ/2*(x - 1)^2 + O((x - 1)^3)

    Laurent series (negative powers), Puiseux series (fractional powers), logarithmic terms and expansions at infinity (in powers of 1/x) are included:

    series(cot(x), x, 0, 4), series(sqrt(x + x^2), x, 0, 3)
    (1/x - x/3 - x^3/45 + O(x^4), sqrt(x) + x^(3/2)/2 - x^(5/2)/8 + O(x^3))
    series(x^x, x, 0, 3), series(sqrt(x^2 + x), x, Inf, 3)
    (1 + log(x)*x + log(x)^2*x^2/2 + O(x^3), x + 1/2 - 1/(8*x) + 1/(16*x^2) + O(1/x^3))

    A series is an object that keeps its error term. Series about the same point can be added, multiplied and divided, with the order tracked, and Sym drops the O term:

    s, c = series(sin(x), x), series(cos(x), x)
s / c
    x + x^3/3 + 2*x^5/15 + O(x^6)
    Sym(s)
    x^5/120 - x^3/6 + x

    Integrals#

    Antiderivatives come from integrate, from RischIntegrate, an implementation of the Risch algorithm. It decides whether an elementary antiderivative exists, and finds it:

    integrate(x^2 * exp(x), x)
    (x^2 - 2*x + 2)*exp(x)
    integrate(1 / (x^3 + 1), x)
    log(x + 1)/3 - log(x^2 - x + 1)/6 + sqrt(3)*atan(sqrt(3)*(2*x/3 - 1/3))/3
    integrate(1 / (x^3 - x), x), integrate((2x + 3) / (x^2 + 1), x)
    (-log(x) + log(x^2 - 1)/2, 3*atan(x) + log(x^2 + 1))
    integrate(sin(x)^3, x), integrate(sqrt(1 - x^2), x)
    (cos(3*x)/12 - 3*cos(x)/4, sqrt(-x^2 + 1)*x/2 + asin(x)/2)
    integrate(x * log(x), x), integrate(1 / (x * log(x)), x)
    (log(x)*x^2/2 - x^2/4, log(log(x)))

    Definite integrals#

    A definite integral is the difference of an antiderivative's values at the end points. Calling the antiderivative with exact numbers keeps the answer exact:

    F = integrate(x^2, x)
F(3) - F(0)
    9//1
    G = integrate(sin(x), x)
G(x => Sym(π)) - G(x => 0)
    2

    What SymJ does not do yet#

    • Simplification under assumptions. solve takes assumptions, but simplification does not yet, so identities such as sqrt(x^2) = x for positive x are not applied.

    • Matrices and noncommutative algebra.

    • Transcendental systems of equations, such as sin(x) ~ y, x ~ y^2 (polynomial and rational systems are solved), and equations in several unrelated functions of the unknown, such as sin(x) + cos(x) ~ 1.
