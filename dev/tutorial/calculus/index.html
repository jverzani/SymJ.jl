    Calculus#

    Limits, derivatives, series, sums, integrals and differential equations.

    Limits#

    limit(f, x => x0) is the limit of f as x tends to x0, a number, an expression or Inf. It is computed by Gruntz's algorithm, through GruntzLimit. An infinite limit is returned as Sym(Inf) or Sym(-Inf):

    limit(sin(x) / x, x => 0)
    \[1\] 
    limit((1 + 1 / x)^x, x => Inf), limit(x * ((1 + 1 / x)^x - ℯ), x => Inf)
    \[\left( e, \; - \frac{e}{2} \right)\]

    Using exact, symbolic numbers is important in many limits.

    limit((sin(x) - sin(Sym(π) / 6)) / (x - Sym(π) / 6), x => Sym(π) / 6)
    \[\frac{\sqrt{3}}{2}\]

    The limit is two-sided unless dir = :+ or dir = :- asks for a one-sided one:

    limit(x * exp(1 / x), x => 0; dir = :-), limit(x^x, x => 0; dir = :+)
    \[\left( 0, \; 1 \right)\]

    All of -, :-, "-", "+", :+, and + can be used to specify a one-sided direction.

    The algorithm handles cancellations that numerical evaluation cannot follow:

    limit(exp(x) * (exp(1 / x - exp(-x)) - exp(1 / x)), x => Inf)
    \[-1\]

    Other symbols may appear:

    limit((1 + a / x)^(b * x), x => Inf)
    \[e^{a \cdot b}\]

    The other symbols are taken to be real numbers. When the limit depends on their values, limit gives it for each case:

    limit(x^a, x => Inf)
    \[\begin{cases} 0 & a < 0 \\ 1 & a = 0 \\ \infty & a > 0 \end{cases}\]

    Assumptions, as in the section on solving, settle cases:

    (
limit(x^a, x => Inf; assume = @assume(a > 1)),
limit((a^x + b^x)^(1 / x), x => Inf; assume = @assume(a > b > 0))
)
    \[\left( \infty, \; a \right)\]

    Derivatives#

    diff(f, x) differentiates with respect to x, and diff(f, x, n) gives the n-th derivative:

    diff(sin(x)^2 * exp(x), x)
    \[2 \cdot \cos\left( x \right) \cdot \sin\left( x \right) \cdot e^{x} + \sin^{2}\left( x \right) \cdot e^{x}\] 
    diff(x^x, x), diff(atan(x), x, 3)
    \[\left( \left( \log\left( x \right) + 1 \right) \cdot x^{x}, \; - \frac{2}{\left( x^{2} + 1 \right)^{2}} + \frac{8 \cdot x^{2}}{\left( x^{2} + 1 \right)^{3}} \right)\]

    Mixed partial derivatives take the variables in order: diff(f, x, y) differentiates with respect to x, then y:

    (
diff(x^3 * y^2, x, y),
diff(sin(x * y), x, y),
diff(x^2 * y * z, x, x, y, z)
)
    \[\left( 6 \cdot x^{2} \cdot y, \; - \sin\left( x \cdot y \right) \cdot x \cdot y + \cos\left( x \cdot y \right), \; 2 \right)\]

    A symbolic function gives an unevaluated derivative:

    diff(f(x^2), x)
    \[2 \cdot \mathrm{f'}\left( x^{2} \right) \cdot x\]

    For implicit differentiation, write y as a function u(x), differentiate, and solve for the derivative:

    @syms u()
F = x^2 + u(x)^2 - 1
solve(diff(F, x) ~ 0, diff(u(x), x))
    \[\left[ - \frac{x}{u\left( x \right)} \right]\]

    Example: critical points#

    The critical points of a function are the zeros of its derivative, and the second derivative classifies them:

    h = x^3 - 6x^2 + 9x + 1
cps = solve(diff(h, x) ~ 0, x)
    \[\left[ 1, \; 3 \right]\] 
    h2 = diff(h, x, 2)
[(c, h(c), h2(c)) for c in cps]
    2-element Vector{Tuple{Sym, Sym, Sym}}:
 (1, 5, -6)
 (3, 1, 6)

    So 1 is a local maximum and 3 a local minimum.

    More complicated equations for finding the critical points are also possible.

    solve(diff((a / x)^x, x) ~ 0, x), solve(diff(x^2 * exp(-x), x) ~ 0, x)
    \[\left( \left[ \frac{a}{e} \right], \; \left[ 0, \; 2 \right] \right)\]

    Example: tangent lines#

    The tangent line at c is h(c) + h'(c)(x - c):

    c₀ = 2
expand(h(c₀) + diff(h, x)(c₀) * (x - c₀))
    \[-3 \cdot x + 9\]

    Integrals#

    Antiderivatives come from integrate, from RischIntegrate, an implementation of the Risch algorithm. It decides whether an elementary antiderivative exists, and finds it when it can.

    integrate(x^2 * exp(x), x)
    \[\left( x^{2} - 2 \cdot x + 2 \right) \cdot e^{x}\] 
    integrate(1 / (x^3 + 1), x)
    \[\frac{\log\left( \left|x + 1\right| \right)}{3} - \frac{\log\left( x^{2} - x + 1 \right)}{6} + \frac{\sqrt{3} \cdot \arctan\left( \sqrt{3} \cdot \left( \frac{2 \cdot x}{3} - \frac{1}{3} \right) \right)}{3}\] 
    integrate(1 / (x^3 - x), x), integrate((2x + 3) / (x^2 + 1), x)
    \[\left( - \log\left( \left|x\right| \right) + \frac{\log\left( \left|x^{2} - 1\right| \right)}{2}, \; 3 \cdot \arctan\left( x \right) + \log\left( x^{2} + 1 \right) \right)\]

    SymJ integrates over the real numbers: the variable of integration and the parameters are taken to be real. This differs from Rubi, Mathematica and SymPy, which take them to be complex and give antiderivatives valid over ℂ (on principal branches). Over ℝ, an antiderivative whose real form depends on the sign of a parameter comes by cases, each case real (assume picks one):

    integrate(1 / (x^2 + a), x)
    \[\begin{cases} \frac{\log\left( \left|\frac{x + \frac{a}{\sqrt{ - a}}}{x - \frac{a}{\sqrt{ - a}}}\right| \right)}{2 \cdot \sqrt{ - a}} & a < 0 \\ \frac{\arctan\left( \frac{x}{\sqrt{a}} \right)}{\sqrt{a}} & a > 0 \end{cases}\] 
    integrate(1 / (x^2 + a), x; assume = @assume(a > 0))
    \[\frac{\arctan\left( \frac{x}{\sqrt{a}} \right)}{\sqrt{a}}\]

    For the same reason a logarithm of an expression that may be negative has its absolute value: ∫ 1/x dx is log|x|, an antiderivative on both sides of 0 (the others give log(x), complex for x < 0). An argument known to be positive keeps the plain log:

    integrate(1 / x, x), integrate(1 / x, x; assume = @assume(x > 0)), integrate(2x / (x^2 + 1), x)
    \[\left( \log\left( \left|x\right| \right), \; \log\left( x \right), \; \log\left( x^{2} + 1 \right) \right)\] 
    integrate(sin(x)^3, x), integrate(sqrt(1 - x^2), x)
    \[\left( \frac{\cos\left( 3 \cdot x \right)}{12} - \frac{3 \cdot \cos\left( x \right)}{4}, \; \frac{\sqrt{ - x^{2} + 1} \cdot x}{2} + \frac{\arcsin\left( x \right)}{2} \right)\] 
    integrate(x * log(x), x), integrate(1 / (x * log(x)), x)
    \[\left( \frac{\log\left( x \right) \cdot x^{2}}{2} - \frac{x^{2}}{4}, \; \log\left( \log\left( x \right) \right) \right)\]

    Piecewise functions, heaviside, abs and sign are integrated interval by interval, the antiderivative made continuous; a dirac picks out a value:

    H = SymJ.heaviside
integrate(x * H(x - 1), x), integrate(cos(x) * SymJ.dirac(x - 1), x)
    \[\left( \begin{cases} 0 & \text{if } x < 1\\ \frac{x^{2}}{2} - \frac{1}{2} & \text{otherwise} \end{cases}, \; \cos\left( 1 \right) \cdot \theta\left( x - 1 \right) \right)\]

    Definite integrals#

    A definite integral is the difference of an antiderivative's values at the end points. Calling the antiderivative with exact numbers keeps the answer exact:

    F = integrate(x^2, x)
F(3) - F(0)
    9//1
    integrate(abs(x - 1), (x, 0, 3))
    \[\frac{5}{2}\]

    integrate(f, (x, a, b)) splits the interval at the points where f is singular and takes one-sided limits there and at infinite limits, so improper integrals come out right; one that diverges is ±∞, or an error when it has no value:

    (integrate(1 / (1 + x^2), (x, 0, Inf)),
integrate(exp(-x^2), (x, -Inf, Inf)), integrate(log(x), (x, 0, 1)),
integrate(1 / x^2, (x, -1, 1)))
    \[\left( \frac{\pi}{2}, \; \sqrt{\pi}, \; -1, \; \infty \right)\]

    Some antiderivatives are known only numerically: RischIntegrate's ₂F₁ terms and sums over the roots of a polynomial, which it can evaluate but SymJ cannot hold. A definite integral through one, over numeric limits where f is not singular, is a float: integrate(x / sqrt(1 - x^3), (x, 0, 1//2)) is 0.12832….

    An integrand proven to have no elementary antiderivative, over numeric limits where the integral converges, gives the integral unevaluated; N (or float, or calling it) finds its value by numeric quadrature (QuadGK's), and SymJ.evalf to a BigFloat precision:

    ex = integrate(exp(x^3), (x, 0, 1))
ex, N(ex), SymJ.evalf(ex, BigFloat, 100)
    (Integral(exp(x^3), (x, 0, 1)), 1.3419044179774198, 1.3419044179774197412491049783146)
    @syms y
ex = integrate(exp(-x^2 * y^2), (x, 0, 1), (y, 0, 1))
ex, N(ex)
    (Integral(erf(y)*sqrt(π)/(2*y), (y, 0, 1)), 0.9059404763223627)

    Before keeping such an integral, SymJ tries differentiation under the integral sign (Feynman's trick). A constant c of the integrand becomes a parameter a, and the integral is found as I(c) = I(a₀) + ∫ I'(a) da from a base point a₀ (0 or 1) where it is known, with I'(a) = ∫ ∂f/∂a dx. Here I'(a) = 2π/√(1 - a²):

    integrate(log((1 + cos(x)/2) / (1 - cos(x)/2)) / cos(x), (x, 0, π))
    \[\frac{\pi^{2}}{3}\]

    A value found this way is kept only when it agrees with the integral's numeric value, so a constant for which the exchange of derivative and integral is not valid gives no answer, never a wrong one.

    SymJ.Integral(f, (x, a, b)) (or SymJ.Integral(f, x)) writes an integral without integrating it; integrate(ex), with no variable, carries out the integrals in ex, keeping those it cannot do:

    I = SymJ.Integral(exp(-x^2), (x, 0, Inf))
I, N(I), integrate(I)
    (Integral(1/exp(x^2), (x, 0, Inf)), 0.8862269254527582, sqrt(π)/2)

    principal_value = true asks for the Cauchy principal value instead: a singular point inside is approached from both sides at once, lim{ε→0⁺} (∫ₐ^{s-ε} + ∫{s+ε}^b) f, and an integral over (-∞, ∞) is the limit of ∫ from -R to R. An integral that converges keeps its value; a singular end point is not crossed, so ∫₀¹ 1/x is still ∞:

    pv(f, ab) = integrate(f, ab; principal_value = true)
(pv(1 / x, (x, -1, 2)),
pv(1 / x^3, (x, -1, 2)),
pv(tan(x), (x, 0, π)),
pv(x / (1 + x^2), (x, -Inf, Inf)))
    \[\left( \log\left( 2 \right), \; \frac{3}{8}, \; 0, \; 0 \right)\]

    With a parameter the answer may depend on its sign; the cases are listed unless the assumptions decide them:

    integrate(exp(-a * x), (x, 0, Inf))
    \[\begin{cases} \infty & a \leq 0 \\ \frac{1}{a} & a > 0 \end{cases}\] 
    integrate(exp(-a * x), (x, 0, Inf); assume = @assume(a > 0))
    \[\frac{1}{a}\]

    Where the formula divides by a parameter, the parameter takes a generic value (nonzero, as for solve); the special value is a case only when assumed:

    @syms c
integrate(exp(c * x), (x, 0, 1))
    \[ - \frac{1}{c} + \frac{e^{c}}{c}\] 
    integrate(exp(c * x), (x, 0, 1); assume = @assume(c == 0))
    \[1\]

    An iterated integral lists its intervals innermost first. The inner integral may have cases on the outer variable (here on the sign of x, for y^m); the outer interval keeps the ones it allows, or is split where they change:

    @syms n m
integrate(x^n * y^m, (y, 0, x), (x, 0, 1); assume = @assume(n > 0, m > 0))
    \[\frac{1}{\left( m + 1 \right) \cdot \left( m + n + 2 \right)}\]

    Implicit assumptions for integration#

    The variable of integration, by default, is assumed to be real, as are the parameters, so the conj that dot puts on symbols drops out. A line integral, the work of ⟨-y, x⟩ around the unit circle:

    using LinearAlgebra: dot
r = [cos(t), sin(t)]
integrate(dot([-r[2], r[1]], diff.(r, t)), (t, 0, 2Sym(π)))
    \[2 \cdot \pi\] 
    G = integrate(sin(x), x)
G(x => Sym(π)) - G(x => 0)
    \[2\]

    Differential equations#

    SymJ.dsolve solves an ordinary differential equation for an unknown function. The function is made with @syms y(), and its derivatives are written y'(x), y''(x) (or diff(y(x), x)). The answer is an equation, with constants C1, C2, …:

    @syms y()
SymJ.dsolve(y'(x) + 2y(x) ~ exp(x), y(x))
    \[y\left( x \right) = \frac{C1}{e^{2 \cdot x}} + \frac{e^{x}}{3}\]

    The `'` operator

    The prime goes on the function, before the call. After the call, ' is Julia's adjoint of the value y(x), its complex conjugate, and not a derivative. That is, these differ: y'(x), y(x)' are quite different.

    First-order equations that are linear, separable, Bernoulli, exact or homogeneous are recognized:

    (
SymJ.dsolve(y'(x) ~ x * y(x)^2, y(x)),
SymJ.dsolve(y'(x) ~ (x + y(x)) / x, y(x))
)
    \[\left( y\left( x \right) = - \frac{2}{x^{2} + C1}, \; y\left( x \right) = \left( C1 + \log\left( x \right) \right) \cdot x \right)\]

    A Riccati equation, y' = q₀ + q₁ y + q₂ y², is made linear (of second order), or solved from a particular solution:

    SymJ.dsolve(y'(x) ~ y(x)^2 - 2 / x^2, y(x))
    \[y\left( x \right) = \frac{-2 \cdot x^{3} + C1}{x^{4} + C1 \cdot x}\]

    When y cannot be solved for, the solution is implicit:

    SymJ.dsolve(2x * y(x) + (x^2 + 3y(x)^2) * y'(x) ~ 0, y(x))
    \[x^{2} \cdot y\left( x \right) + \left( y\left( x \right) \right)^{3} = C1\]

    Linear equations with constant coefficients, of any order, are solved through the roots of the characteristic polynomial; a right side is handled by undetermined coefficients, or by variation of parameters:

    (
SymJ.dsolve(y''(x) + 2y'(x) + 5y(x) ~ 0, y(x)),
SymJ.dsolve(y''(x) + y(x) ~ sin(x), y(x))
)
    \[\left( y\left( x \right) = \frac{C1 \cdot \cos\left( 2 \cdot x \right) + C2 \cdot \sin\left( 2 \cdot x \right)}{e^{x}}, \; y\left( x \right) = C1 \cdot \cos\left( x \right) + C2 \cdot \sin\left( x \right) - \frac{\cos\left( x \right) \cdot x}{2} \right)\] 
    SymJ.dsolve(y''(x) + y(x) ~ tan(x), y(x))
    \[y\left( x \right) = C1 \cdot \cos\left( x \right) + C2 \cdot \sin\left( x \right) + \frac{\cos\left( x \right) \cdot \log\left( -2 \cdot \sin\left( x \right) + 2 \right)}{2} - \frac{\cos\left( x \right) \cdot \log\left( 2 \cdot \sin\left( x \right) + 2 \right)}{2}\]

    Cauchy–Euler equations, with coefficients x^k on y⁽ᵏ⁾, are solved too:

    SymJ.dsolve(x^2 * y''(x) - 2y(x) ~ 0, y(x))
    \[y\left( x \right) = C2 \cdot x^{2} + \frac{C1}{x}\]

    An equation of second order without x, y'' = f(y, y'), is reduced to first order with p = y' as a function of y:

    SymJ.dsolve(y(x) * y''(x) ~ y'(x)^2, y(x))
    \[y\left( x \right) = e^{C1 \cdot \left( C2 + x \right)}\]

    When y' has two branches, ±sqrt(…), there is a solution for each; initial conditions pick one:

    SymJ.dsolve(y''(x) ~ 2y(x)^3, y(x), y(0) => 1, y'(0) => 1)
    \[y\left( x \right) = - \frac{1}{x - 1}\]

    Initial conditions, one for each order, fix the constants:

    SymJ.dsolve(y''(x) + y(x) ~ 0, y(x), y(0) => 0, y'(0) => 1)
    \[y\left( x \right) = \sin\left( x \right)\] 
    SymJ.dsolve(y'(x) ~ -x / y(x), y(x), y(0) => 2)
    \[y\left( x \right) = \sqrt{ - x^{2} + 4}\]

    With series = n the solution is a series, here about 0 (Airy's equation), with error O(x^n):

    SymJ.dsolve(y''(x) - x * y(x) ~ 0, y(x); series = 8)
    \[y\left( x \right) = C2 \cdot \left( \frac{x^{7}}{504} + \frac{x^{4}}{12} + x \right) + C1 \cdot \left( \frac{x^{6}}{180} + \frac{x^{3}}{6} + 1 \right)\]

    At a regular singular point it is a Frobenius series, which can have a log term (Bessel's equation of order 0):

    SymJ.dsolve(x^2 * y''(x) + x * y'(x) + x^2 * y(x) ~ 0, y(x); series = 6)
    \[y\left( x \right) = C1 \cdot \left( \frac{x^{4}}{64} - \frac{x^{2}}{4} + 1 \right) + C2 \cdot \left( \log\left( x \right) \cdot \left( \frac{x^{4}}{64} - \frac{x^{2}}{4} + 1 \right) - \frac{3 \cdot x^{4}}{128} + \frac{x^{2}}{4} \right)\]

    A right side with a step or an impulse (SymJ.heaviside, SymJ.dirac) is handled by Laplace transforms:

    SymJ.dsolve(y''(x) + y(x) ~ SymJ.heaviside(x - 1), y(x), y(0) => 0, y'(0) => 0)
    \[y\left( x \right) = \left( - \cos\left( x - 1 \right) + 1 \right) \cdot \theta\left( x - 1 \right)\]

    The transforms themselves are SymJ.laplace_transform and SymJ.inverse_laplace_transform:

    @syms s
(
SymJ.laplace_transform(x * sin(x), x, s),
SymJ.inverse_laplace_transform(exp(-2s) / (s^2 + 1), s, x)
)
    \[\left( \frac{2 \cdot s}{\left( s^{2} + 1 \right)^{2}}, \; \theta\left( x - 2 \right) \cdot \sin\left( x - 2 \right) \right)\]

    A system of linear equations with constant coefficients is given as vectors of equations and unknowns. The answer is a vector of equations:

    @syms t u() v()
SymJ.dsolve([u'(t) ~ u(t) - v(t), v'(t) ~ 5u(t) - 3v(t)], [u(t), v(t)])
    \[\left[ \begin{array}{l} u\left( t \right) = \frac{2 \cdot C1 \cdot \cos\left( t \right) - C1 \cdot \sin\left( t \right) - C2 \cdot \cos\left( t \right) - 2 \cdot C2 \cdot \sin\left( t \right)}{5 \cdot e^{t}} \\ v\left( t \right) = \frac{C1 \cdot \cos\left( t \right) - C2 \cdot \sin\left( t \right)}{e^{t}} \end{array} \right]\]

    Higher derivatives, right sides and initial conditions (one for each unknown and each order below its highest) are allowed:

    SymJ.dsolve([u''(t) + v(t) ~ 0, v'(t) ~ u(t) + t], [u(t), v(t)], u(0) => 1, u'(0) => 0, v(0) => 0)
    \[\left[ \begin{array}{l} u\left( t \right) = - t - \frac{\left( -2 \cdot \cos\left( \frac{\sqrt{3} \cdot t}{2} \right) - \frac{2 \cdot \sqrt{3} \cdot \sin\left( \frac{\sqrt{3} \cdot t}{2} \right)}{3} \right) \cdot e^{\frac{t}{2}}}{2} \\ v\left( t \right) = \frac{2 \cdot \sqrt{3} \cdot \sin\left( \frac{\sqrt{3} \cdot t}{2} \right) \cdot e^{\frac{t}{2}}}{3} \end{array} \right]\]

    Series#

    series(ex, x, x0, n) expands ex about x0 with an error of order (x - x0)^n; x0 defaults to 0 and n to 6:

    series(sin(x), x)
    \[x - \frac{x^{3}}{6} + \frac{x^{5}}{120} + O\left( x^{6} \right)\] 
    series(exp(x), x, 1, 3)
    \[e + e \cdot \left( x - 1 \right) + \frac{e}{2} \cdot \left( x - 1 \right)^{2} + O\left( \left( x - 1 \right)^{3} \right)\]

    Laurent series (negative powers), Puiseux series (fractional powers), logarithmic terms and expansions at infinity (in powers of 1/x) are included:

    (
series(cot(x), x, 0, 4),
series(sqrt(x + x^2), x, 0, 3)
)
    \[\left( \frac{1}{x} - \frac{x}{3} - \frac{x^{3}}{45} + O\left( x^{4} \right), \; \sqrt{x} + \frac{x^{\frac{3}{2}}}{2} - \frac{x^{\frac{5}{2}}}{8} + O\left( x^{3} \right) \right)\] 
    (
series(x^x, x, 0, 3),
series(sqrt(x^2 + x), x, Inf, 3)
)
    \[\left( 1 + \log\left( x \right) \cdot x + \frac{\left( \log\left( x \right) \right)^{2} \cdot x^{2}}{2} + O\left( x^{3} \right), \; x + \frac{1}{2} - \frac{1}{8 \cdot x} + \frac{1}{16 \cdot x^{2}} + O\left( \frac{1}{x^{3}} \right) \right)\]

    At ±Inf an expansion may need a factor that is not a power of x: terms exp(g)*(series), cos(h)*(series) and sin(h)*(series), from exp, sin and cos of growing arguments and from the asymptotic expansions of SpecialFunctions' erf, erfc, erfi, erfcx, expinti, expint, sinint, cosint, the Bessel functions and gamma (Stirling's series; the special functions need to be brought in from SpecialFunctions to be used directly). Factors that cancel do cancel:

    series(sin(x) / x + exp(-x) * (1 + 1/x), x, Inf, 4)
    \[\sin\left( x \right) \cdot \left( \frac{1}{x} + O\left( \frac{1}{x^{4}} \right) \right) + \frac{1}{e^{x}} \cdot \left( 1 + \frac{1}{x} + O\left( \frac{1}{x^{4}} \right) \right) + O\left( \frac{1}{x^{4}} \right)\] 
    using SpecialFunctions: erf, erfc
series(erf(x), x, Inf, 4)
    \[1 + \frac{1}{e^{x^{2}}} \cdot \left( - \frac{1}{x \cdot \sqrt{\pi}} + \frac{1}{2 \cdot x^{3} \cdot \sqrt{\pi}} + O\left( \frac{1}{x^{4}} \right) \right)\]

    Exponentially small terms are kept: erf(x) at Inf is not just 1.

    series(exp(x^2) * erfc(x), x, Inf, 4)
    \[\frac{1}{x \cdot \sqrt{\pi}} - \frac{1}{2 \cdot x^{3} \cdot \sqrt{\pi}} + O\left( \frac{1}{x^{4}} \right)\]

    A series is an object that keeps its error term. Series about the same point can be added, multiplied and divided, with the order tracked:

    s, c = series(sin(x), x), series(cos(x), x)
s / c
    \[x + \frac{x^{3}}{3} + \frac{2 \cdot x^{5}}{15} + O\left( x^{6} \right)\]

    Calling Sym on a series drops the O term:

    Sym(s)
    \[\frac{x^{5}}{120} - \frac{x^{3}}{6} + x\]

    Sums#

    SymJ.summation(f, (k, a, b)) (not exported) sums f over k = a, …, b, in closed form where it finds one; b may be Inf:

    @syms k n r
(
SymJ.summation(k^2, (k, 1, n)),
SymJ.summation(r^k, (k, 0, n)),
SymJ.summation(1 / (k * (k + 1)), (k, 1, n))
)
    \[\left( \frac{\left( 2 \cdot n + 1 \right) \cdot n \cdot \left( n + 1 \right)}{6}, \; \frac{r^{n + 1} - 1}{r - 1}, \; \frac{n}{n + 1} \right)\] 
    (
SymJ.summation(1 / k^2, (k, 1, Inf)),
SymJ.summation(x^k / factorial(k), (k, 0, Inf))
)
    \[\left( \frac{\pi^{2}}{6}, \; e^{x} \right)\]

    Definite sums of binomials, which have no antidifference, come from Zeilberger's algorithm:

    @syms m
(
SymJ.summation(binomial(n, k)^2, (k, 0, n)),
SymJ.summation(binomial(n, k) * binomial(m, n - k), (k, 0, n))
)
    \[\left( \binom{2 \cdot n}{n}, \; \binom{m + n}{m} \right)\]

    When Zeilberger's recurrence is of higher order, its hypergeometric solutions (found by Petkovšek's algorithm Hyper) may still give the sum; here Binet's formula for the Fibonacci numbers:

    SymJ.summation(binomial(n - k, k), (k, 0, n))
    \[\left( - \frac{\sqrt{5}}{10} + \frac{1}{2} \right) \cdot \left( - \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n} + \left( \frac{\sqrt{5}}{10} + \frac{1}{2} \right) \cdot \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n}\]

    Bounds other than the summand's own give an inhomogeneous recurrence, solved as well:

    (
SymJ.summation(binomial(n, k), (k, 0, n - 1)),
SymJ.summation(binomial(2n, k), (k, 0, n))
)
    \[\left( 2^{n} - 1, \; \frac{4^{n}}{2} + \frac{\binom{2 \cdot n}{n}}{2} \right)\]

    The same algorithm solves linear recurrences, SymJ.rsolve (not exported), from initial values or in terms of them:

    @syms w()
(
SymJ.rsolve(w(n + 2) ~ w(n + 1) + w(n), w(n), w(0) => 0, w(1) => 1),
SymJ.rsolve(w(n + 1) ~ 2w(n) + 1, w(n))
)
    \[\left( \frac{\sqrt{5} \cdot \left( - \left( - \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n} + \left( \frac{\sqrt{5}}{2} + \frac{1}{2} \right)^{n} \right)}{5}, \; 2^{n} \cdot \left( w\left( 0 \right) + 1 \right) - 1 \right)\]

    When a recurrence has too few hypergeometric solutions, its order is reduced through one of them; the solutions are then iterated sums of hypergeometric terms (harmonic numbers, or a Sum that does not close), and the right side may be any function of n:

    (
SymJ.rsolve(w(n + 1) - w(n) ~ 1 / (n + 1), w(n), w(0) => 0),
SymJ.rsolve(w(n + 1) ~ (n + 1) * w(n) + 1, w(n), w(0) => 1)
)
    \[\left( \mathrm{harmonic}\left( n \right), \; \left( \sum_{k=0}^{n - 1} \frac{1}{\mathrm{factorial}\left( k + 1 \right)} + 1 \right) \cdot \mathrm{factorial}\left( n \right) \right)\] 
    SymJ.summation((-1)^(k + 1) * binomial(n, k) / k, (k, 1, n))
    \[\mathrm{harmonic}\left( n \right)\]

    Solutions that are hypergeometric only on every second (or m-th) term are found too, as piecewise functions of mod(n, m):

    SymJ.summation((-1)^k * binomial(n, k)^2, (k, 0, n))
    \[\begin{cases} 0 \Rightarrow \left( -1 \right)^{\frac{n}{2}} \cdot \binom{n}{\frac{n}{2}} & \text{if } \mathrm{mod}\left( n, 2 \right)\\ 0 & \text{otherwise} \end{cases}\]

    With no closed form, rsolve returns the recurrence itself, which is evaluated at integers by unrolling it:

    F = SymJ.rsolve((n + 2)^2 * w(n + 2) - (7n^2 + 21n + 16) * w(n + 1) - 8(n + 1)^2 * w(n) ~ 0, w(n), w(0) => 1, w(1) => 2)
    \[\mathrm{DifferenceRoot}\left( \left( n + 2 \right)^{2} \cdot w\left( n + 2 \right) - \left( 7 \cdot n^{2} + 21 \cdot n + 16 \right) \cdot w\left( n + 1 \right) - 8 \cdot \left( n + 1 \right)^{2} \cdot w\left( n \right) = 0,\; w\left( 0 \right) = 1,\; w\left( 1 \right) = 2 \right)\] 
    [subs(F, n => m) for m in 0:6]
    \[\left[ 1, \; 2, \; 10, \; 56, \; 346, \; 2252, \; 15184 \right]\]

    Harmonic numbers times a term that has an antidifference are summed by parts:

    SymJ.summation(k * SymJ.harmonic(k), (k, 1, n))
    \[\frac{\mathrm{harmonic}\left( n \right) \cdot n \cdot \left( n + 1 \right)}{2} - \frac{n \cdot \left( n - 1 \right)}{4}\]

    SymJ.harmonic(n, m) is the generalized harmonic number 1 + 1/2^m + ... + 1/n^m:

    (
SymJ.summation(1 / k^2, (k, 1, n)),
SymJ.summation(SymJ.harmonic(k) / k, (k, 1, n))
)
    \[\left( \mathrm{harmonic}\left( n, 2 \right), \; \frac{\left( \mathrm{harmonic}\left( n \right) \right)^{2}}{2} + \frac{\mathrm{harmonic}\left( n, 2 \right)}{2} \right)\]

    Whether a series converges can depend on a parameter; the answer then has cases, which assumptions settle:

    SymJ.summation(r^k, (k, 0, Inf))
    \[\begin{cases} \text{the series diverges} & r \leq -1 \\ \frac{1}{ - r + 1} & -1 < r < 1 \\ \text{the series diverges} & r \geq 1 \end{cases}\] 
    SymJ.summation(k * r^k, (k, 0, Inf); assume = @assume(0 < r < 1))
    \[\frac{r}{\left( r - 1 \right)^{2}}\]
